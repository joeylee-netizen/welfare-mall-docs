# /ux-audit — 접근성 및 사용성 감사

## 설명
HTML 와이어프레임의 접근성(WCAG 2.1 AA)과 사용성을 감사한다.

## 사용법
```
/ux-audit BO-PDM-040                          # 특정 화면 감사
/ux-audit domains/BO/product/05-wireframes/   # 도메인 전체 감사
```

## 감사 항목

### 접근성 (WCAG 2.1 AA)

#### A-1. 대체 텍스트
- [ ] 모든 `<img>`에 `alt` 속성 존재
- [ ] 장식용 이미지는 `alt=""` + `role="presentation"`

#### A-2. 폼 레이블
- [ ] 모든 `<input>`, `<select>`, `<textarea>`에 연결된 `<label>` 또는 `aria-label`
- [ ] 필수 필드에 `required` 속성 또는 `aria-required="true"`
- [ ] placeholder만으로 레이블 대체하지 않음

#### A-3. 키보드 접근
- [ ] 모든 인터랙티브 요소에 키보드 도달 가능
- [ ] 포커스 순서가 논리적 (탭 순서)
- [ ] 포커스 표시(outline) 제거하지 않음

#### A-4. 색상 대비
- [ ] 텍스트 대비율 4.5:1 이상 (일반 텍스트)
- [ ] 대형 텍스트(18px+) 대비율 3:1 이상
- [ ] 색상만으로 상태 구분하지 않음 (텍스트/아이콘 병행)

#### A-5. 시맨틱 HTML
- [ ] `<header>`, `<nav>`, `<main>`, `<section>` 적절히 사용
- [ ] 제목 계층 순서 준수 (h1 → h2 → h3, 건너뛰기 없음)
- [ ] `<button>` vs `<a>` 올바른 사용 (액션 vs 네비게이션)

#### A-6. 모달/다이얼로그
- [ ] `<dialog>` 또는 `role="dialog"` 사용
- [ ] 열릴 때 포커스 이동
- [ ] ESC 키로 닫기 가능
- [ ] 배경 스크롤 방지

### 사용성

#### U-1. 정보 구조
- [ ] 페이지 제목이 명확
- [ ] 빵크럼 또는 현재 위치 표시
- [ ] 빈 상태(empty state) 안내 메시지

#### U-2. 액션 일관성
- [ ] 주요 액션(등록/저장) 버튼 위치 통일
- [ ] 파괴적 액션(삭제)에 확인 절차
- [ ] 버튼 라벨이 동작을 명확히 설명 ("확인" 대신 "저장", "삭제")

#### U-3. 피드백
- [ ] 성공/실패 메시지 표시 방식 정의
- [ ] 로딩 상태 표시 설계
- [ ] 유효성 검사 에러 위치 및 메시지
