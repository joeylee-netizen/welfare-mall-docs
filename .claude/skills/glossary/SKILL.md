# /glossary — 용어집 관리

## 설명
프로젝트 내 사용되는 용어를 통일하고 관리한다.
기획 문서 전반에서 동일 개념에 다른 용어가 사용되는 것을 방지한다.

## 사용법
```
/glossary                          # 전체 용어집 출력
/glossary 상품                     # 특정 용어 검색
/glossary --check BO-PDM-001       # 문서 내 용어 일관성 검사
/glossary --add 복지포인트 "임직원에게 지급되는 복지 혜택 포인트"  # 용어 추가
```

## 용어집 파일

경로: `domains/common/glossary.md`

```markdown
|------|------|------|------|

## ㄴ

| 용어 | 정의 | 영문 | 비고 |
|------|------|------|------|

```

## 기능

### 1. 용어 조회
- 용어집에서 키워드 검색
- 초성별 분류 출력

### 2. 용어 추가
- 새 용어를 `glossary.md`에 추가
- 초성에 맞는 섹션에 자동 배치
- 중복 용어 체크

### 3. 용어 일관성 검사 (--check)
특정 문서 또는 전체 문서에서 용어 불일치를 탐지한다.

#### 검사 규칙
- 동일 개념에 다른 표현 사용 (예: "상품"과 "제품" 혼용)
- 용어집에 미등록 전문 용어 사용
- 약어 미정의 사용

#### 알려진 동의어 패턴
| 표준 용어 | 비표준 (탐지 대상) |
|----------|------------------|
| 상품 | 제품, 물품, 아이템 |
| 클레임 | 컴플레인, 불만, CS |
| 복지포인트 | 포인트, 복지금, 혜택금 |
| 관리자 | 어드민, 운영자, 매니저 |
| 임직원 | 직원, 사원, 구성원 |

## 출력 형식

### 조회
```
📖 용어: 복지포인트
정의: 임직원에게 지급되는 복지 혜택 포인트
영문: Welfare Point
```

### 일관성 검사
```
🔍 용어 일관성 검사: BO-PDM-001

  ⚠️ Line 15: "제품" → 표준 용어 "상품" 사용 권장
  ⚠️ Line 23: "포인트" → 표준 용어 "복지포인트" 사용 권장
  ✅ "클레임" — 표준 용어 사용

---
검사 결과: 표준 N / 비표준 N
```
