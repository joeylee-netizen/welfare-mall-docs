# 상품 상세 폼

## 개요

BO 관리자가 개별 상품의 상세 정보를 조회하고, 승인완료 상품을 수정하는 폼 컴포넌트이다. [BO-PDM-001](../01-policies/BO-PDM-001_상품-관리-정책.md)의 정책에 따라 **승인완료(APPROVED) 상태의 상품만 수정 가능**하며, 수정 시 즉시 FO에 반영된다. 상품 목록([BO-PDM-020](./BO-PDM-020_상품-목록-테이블.md))에서 행 클릭 시 진입한다.

---

## 폼 구성

### 섹션 1: 기본정보

| No | 필드명 | 데이터 필드 | 입력 유형 | 조회 모드 | 수정 모드 | 비고 |
|----|--------|------------|-----------|-----------|-----------|------|
| 1 | 상품코드 | product_code | Text | 읽기전용 | 읽기전용 | 승인완료 전이면 `-` 표시 |
| 2 | 요청코드 | request_code | Text | 읽기전용 | 읽기전용 | |
| 3 | 상품유형 | product_type | Text | 읽기전용 | 읽기전용 | Enum label 표시 |
| 4 | 상품구분 | product_category | Text | 읽기전용 | 읽기전용 | 배송형 / 티켓형 |
| 5 | 상품명 | product_name | Text | 읽기전용 | 편집가능 | 최대 200자 |
| 6 | 브랜드/판매사 | brand_id / vendor_id | Text | 읽기전용 | 읽기전용 | 브랜드명 또는 판매사명 표시 |

### 섹션 2: 상태정보

| No | 필드명 | 데이터 필드 | 입력 유형 | 조회 모드 | 수정 모드 | 비고 |
|----|--------|------------|-----------|-----------|-----------|------|
| 1 | 승인상태 | approval_status | Badge | 읽기전용 | 읽기전용 | 상태별 색상 badge |
| 2 | 판매상태 | sales_status | Select | 읽기전용 | 편집가능 | 전환 가능 상태만 옵션에 표시 |
| 3 | 판매시작일 | sales_start_date | DatePicker | 읽기전용 | 편집가능 | `YYYY-MM-DD` |
| 4 | 판매종료일 | sales_end_date | DatePicker | 읽기전용 | 편집가능 | 시작일 이후만 선택 가능 |

#### 판매상태 변경 규칙

승인완료 상태에서 관리자가 수동 변경 가능한 전환:

| 현재 상태 | 변경 가능 상태 |
|-----------|---------------|
| 판매중 | 판매일시중지, 판매종료 |
| 판매일시중지 | 판매중 |
| 일시품절 | 판매중 |
| 품절 | 판매중 |

> `일시품절` → `품절`, `판매중` → `일시품절`은 시스템 자동 전환이므로 관리자 수동 변경 불가.

### 섹션 3: 승인 이력

[BO-PDM-010](../02-data/BO-PDM-010_상품-엔티티.md)의 ProductApprovalHistory 엔티티 기반.

| No | 컬럼명 | 데이터 필드 | 타입 | 비고 |
|----|--------|------------|------|------|
| 1 | No | - | number | 행 번호 |
| 2 | 행위 | action | text | ApprovalAction Enum label |
| 3 | 이전 상태 | previous_status | badge | 승인상태 badge |
| 4 | 변경 상태 | new_status | badge | 승인상태 badge |
| 5 | 반려사유 | rejection_reason | text | REJECT 시에만 표시 |
| 6 | 변경자 | changed_by | text | |
| 7 | 변경일시 | changed_at | datetime | `YYYY-MM-DD HH:mm` |

- 최신순 정렬 (변경일시 desc)
- 읽기전용 테이블, 최대 10건 표시 + 더보기

### 섹션 4: 판매 상태 변경 로그

[BO-PDM-010](../02-data/BO-PDM-010_상품-엔티티.md)의 ProductSalesStatusLog 엔티티 기반.

| No | 컬럼명 | 데이터 필드 | 타입 | 비고 |
|----|--------|------------|------|------|
| 1 | No | - | number | 행 번호 |
| 2 | 이전 상태 | previous_status | badge | 판매상태 badge |
| 3 | 변경 상태 | new_status | badge | 판매상태 badge |
| 4 | 변경 유형 | change_type | text | 수동 / 자동 |
| 5 | 변경 사유 | change_reason | text | |
| 6 | 변경자 | changed_by | text | 자동 변경 시 `시스템` |
| 7 | 변경일시 | changed_at | datetime | `YYYY-MM-DD HH:mm` |

- 최신순 정렬 (변경일시 desc)
- 읽기전용 테이블, 최대 10건 표시 + 더보기

## 인터랙션

### 조회 모드 (기본)

1. 목록에서 행 클릭 시 `product_id`로 상품 상세 정보 조회
2. 모든 필드가 읽기전용으로 표시
3. 승인상태가 `APPROVED`인 경우에만 하단에 `수정` 버튼 표시

### 수정 모드 전환

1. `수정` 버튼 클릭
2. 편집 가능 필드가 활성화 (상품명, 판매상태, 판매기간)
3. `수정` 버튼이 `저장` / `취소` 버튼으로 변경

### 저장

1. `저장` 버튼 클릭
2. 클라이언트 검증 수행:
   - 상품명: 빈 값 불가, 200자 이내
   - 판매종료일: 판매시작일 이후
3. 검증 통과 시 확인 모달: "수정 사항을 저장하시겠습니까? 즉시 FO에 반영됩니다."
4. 확인 시 API 호출하여 저장
5. 저장 완료 시 조회 모드로 전환 + 성공 토스트 표시

### 판매상태 변경

1. 수정 모드에서 판매상태 Select 변경
2. 변경 가능 상태만 옵션에 표시 (판매상태 변경 규칙 참조)
3. 저장 시 판매 상태 변경 로그가 자동 기록됨

### 목록으로 돌아가기

1. `목록으로` 버튼 클릭
2. 수정 모드에서 변경사항이 있는 경우: "저장하지 않은 변경 사항이 있습니다. 이동하시겠습니까?" 확인 모달
3. 확인 시 상품 목록([BO-PDM-020](./BO-PDM-020_상품-목록-테이블.md))으로 이동
4. 이전 검색 조건 유지

## 상태 처리

| 상태 | 설명 | UI 표현 |
|------|------|---------|
| 조회 | 상품 상세 정보 표시 | 모든 필드 읽기전용, APPROVED 시 수정 버튼 표시 |
| 수정 모드 | 편집 가능 필드 활성화 | 편집 필드 활성화, 저장/취소 버튼 표시 |
| 저장 중 | API 호출 중 | 저장 버튼 로딩 상태, 폼 비활성화 |
| 저장 완료 | 저장 성공 | 조회 모드 전환, 성공 토스트 표시 |
| 오류 | API 호출 실패 또는 검증 실패 | 오류 토스트 또는 필드별 인라인 오류 메시지 |

### 승인상태별 편집 가능 여부

| 승인상태 | 수정 버튼 | 편집 가능 필드 | 비고 |
|---------|:---------:|---------------|------|
| REGISTERING (상품등록중) | X | 없음 | PO 영역 |
| PENDING (승인대기) | X | 없음 | 수정 불가 상태 |
| WITHDRAWN (승인철회) | X | 없음 | PO 영역 |
| APPROVED (승인완료) | O | 상품명, 판매상태, 판매기간 | 수정 즉시 FO 반영 |
| REJECTED (승인반려) | X | 없음 | PO 수정 후 재요청 필요 |
