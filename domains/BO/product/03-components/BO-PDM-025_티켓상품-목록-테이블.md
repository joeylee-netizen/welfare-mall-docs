# 티켓상품 목록 테이블

## 개요

BO 관리자가 승인완료된 티켓형 상품을 조회·검색·관리하는 목록 화면 컴포넌트이다. [BO-PDM-001](../01-policies/BO-PDM-001_상품-관리-정책.md)의 메뉴 구조 중 **상품 관리 > 티켓상품 관리 > 티켓상품 목록**에 해당하며, 목록에서 상품명 클릭 시 티켓상품 등록/수정 폼([BO-PDM-021](./BO-PDM-021_티켓상품-등록수정-폼.md))의 수정 모드로 이동한다.

- 조회 대상: product_category = `TICKET` (티켓형) + approval_status = `APPROVED` (승인완료) 상품
- product_type 범위: `TICKET_COUPON`, `TICKET_RESERVATION`

## 검색 필터 구성 (12개)

| No | 필터명 | 데이터 필드 | 입력 유형 | 기본값 | 비고 |
|----|--------|------------|-----------|--------|------|
| 1 | 카테고리 | category_id | Select 연동 | 전체 | 표준카테고리/전시카테고리 택1 → 1차 → 2차 → 3차 순차 선택 |
| 2 | 판매사 | vendor_id | 조회 팝업 + 드롭박스 | - | 팝업 선택 → 판매사명 출력. 하위업체: 판매사 선택 시 활성화 |
| 3 | MD | md_id | 조회 팝업 | - | 팝업 선택 → MD명 출력 |
| 4 | 외부연동 | registration_source | 체크박스 | 전체 | 전체/직접등록/외부연동 |
| 5 | 브랜드 | brand_id | 조회 팝업 | - | 팝업 선택 → 브랜드명 출력 (티켓형은 선택적) |
| 6 | 모델명 | model_name | Text | - | 부분 일치(LIKE) 검색 |
| 7 | 기간 | created_at / updated_at | Select + DateRange + Radio | 상품등록일, 최근 7일 | 기간유형: 상품등록일/최종수정일. 퀵선택: 오늘/최근7일/1개월/3개월/1년 |

| 11 | 노출채널 | display_channel | 체크박스 | 전체 | 전체/PC/모바일 |

- 필터 영역은 접힘/펼침 가능하며, 기본 펼침 상태이다.
- `검색` 버튼 클릭 또는 Enter 키로 조회를 실행한다.
- `초기화` 버튼 클릭 시 모든 필터를 기본값으로 되돌린다.

- 테이블: 전체 너비 사용, 고정 헤더, 가로 스크롤
- 페이지네이션: 하단 중앙 배치

## 인터랙션

### 검색

1. 필터 조건 입력 후 `검색` 버튼 클릭 또는 Enter 키 입력
2. 입력된 조건 + product_category=TICKET + approval_status=APPROVED 필터로 API 호출
3. 결과를 테이블에 표시하고 검색결과 건수를 갱신
4. 페이지네이션은 1페이지로 초기화

### 초기화

1. `초기화` 버튼 클릭
2. 모든 필터를 기본값으로 되돌림
3. 자동으로 재검색하지 않음 (사용자가 검색 버튼을 다시 눌러야 함)

### 정렬

1. 정렬 가능 컬럼(등록일)의 헤더 클릭
2. asc → desc → 기본 순서로 토글
3. 정렬 변경 시 현재 필터 조건 유지한 채 재조회

### 행 클릭 → 수정 폼 이동

1. 테이블 행의 상품명 링크 클릭
2. 티켓상품 등록/수정 폼([BO-PDM-021](./BO-PDM-021_티켓상품-등록수정-폼.md))의 수정 모드로 이동
3. URL 파라미터로 `product_id` 전달
4. APPROVED 상태이므로 상품명, 판매상태, 판매기간만 편집 가능

### 페이지네이션

1. 페이지 번호 또는 이전/다음 버튼 클릭
2. 현재 필터 조건 유지한 채 해당 페이지 데이터 조회
3. 스크롤 위치를 테이블 상단으로 이동

### 출력개수 변경

1. 출력개수 셀렉트에서 값 변경 (20/50/100)
2. 1페이지로 초기화하여 재조회

## 상태 처리

| 상태 | 설명 | UI 표현 |
|------|------|---------|
| 초기 | 페이지 최초 진입 | 기본 필터 조건으로 자동 검색 |
| 로딩 | API 호출 중 | 테이블 영역에 로딩 스피너(skeleton) 표시, 검색 버튼 비활성화 |
| 데이터 없음 | 조회 결과 0건 | "조회 결과가 없습니다." 메시지 + [필터 초기화] 버튼 |
| 조회 완료 | 데이터 정상 반환 | 테이블에 데이터 표시, 검색결과 건수 갱신 |
| 오류 (400) | 요청 파라미터 오류 | 토스트: "입력 조건을 확인해 주세요." |
| 오류 (409) | 상태 충돌 | 토스트: "상품 상태가 변경되었습니다. 목록을 갱신합니다." + 자동 재조회 |
| 오류 (500) | 서버 오류 | 토스트: "서버 오류가 발생했습니다. 잠시 후 다시 시도해 주세요." + [재시도] 버튼 |
| 네트워크 오류 | 연결 실패 | 토스트: "네트워크 연결을 확인해 주세요." |
