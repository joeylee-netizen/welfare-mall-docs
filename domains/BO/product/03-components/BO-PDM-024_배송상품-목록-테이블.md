# 배송상품 목록 테이블

## 개요

BO 관리자가 승인완료된 배송형 상품을 조회·검색·관리하는 목록 화면 컴포넌트이다. [BO-PDM-001](../01-policies/BO-PDM-001_상품-관리-정책.md)의 메뉴 구조 중 **상품 관리 > 상품 목록 > 배송상품 목록**에 해당하며, 목록에서 행 클릭 시 배송상품 등록/수정 폼([BO-PDM-020](./BO-PDM-020_배송상품-등록수정-폼.md))의 수정 모드로 이동한다.

- 조회 대상: product_category = `SHIPPING` (배송형) + approval_status = `APPROVED` (승인완료) 상품
- product_type 범위: `GENERAL_SHIPPING`, `INSTALLATION`

---

## 검색 필터 구성

| No | 필터명 | 데이터 필드 | 입력 유형 | 기본값 | 비고 |
|----|--------|------------|-----------|--------|------|
| 1 | 상품유형 | product_type | Select | 전체 | GENERAL_SHIPPING, INSTALLATION만 표시 |
| 2 | 판매상태 | sales_status | Select | 전체 | SalesStatus Enum 옵션 |
| 3 | 브랜드 | brand_id | Text (자동완성) | - | 브랜드명 검색 |
| 4 | 상품명 | product_name | Text | - | 부분 일치(LIKE) 검색 |
| 5 | 등록기간 | created_at | DateRange | 최근 1개월 | 시작일 ~ 종료일 |

- 필터 영역은 접힘/펼침 가능하며, 기본 펼침 상태이다.
- `검색` 버튼 클릭 또는 Enter 키로 조회를 실행한다.
- `초기화` 버튼 클릭 시 모든 필터를 기본값으로 되돌린다.

## 컬럼 구성

| No | 컬럼명 | 데이터 필드 | 타입 | 정렬 | 비고 |
|----|--------|------------|------|------|------|
| 1 | No | - | number | - | 행 번호 (페이지 기준 자동 채번) |
| 2 | 상품코드 | product_code | text | - | |
| 3 | 요청코드 | request_code | text | - | |
| 4 | 상품명 | product_name | text | - | 링크 스타일, 클릭 시 수정 폼 이동 |
| 5 | 상품유형 | product_type | text | - | Enum label 표시 |
| 6 | 판매상태 | sales_status | badge | - | 상태별 색상 badge |
| 7 | 브랜드 | brand_id | text | - | 브랜드명 표시 |
| 8 | 판매기간 | sales_start_date ~ sales_end_date | text | - | `YYYY-MM-DD ~ YYYY-MM-DD` 형식 |
| 9 | 등록일 | created_at | date | desc | `YYYY-MM-DD` 형식, 기본 정렬 |

```

│ ┌──────────────┬──────────────┬────────────┐│
│ │ 상품유형      │ 판매상태      │ 브랜드     ││

├─────────────────────────────────────────────┤
│ 배송상품 목록 테이블                           │
│ No | 상품코드 | 요청코드 | 상품명 | 유형 | ...  │
│ ─────────────────────────────────────────── │

│  2 | P00002  | R00002  | 상품B  | ...  | ...  │

├─────────────────────────────────────────────┤
│ 페이지네이션: [<] 1 2 3 ... [>]               │
```

- 필터 영역: 3열 그리드, 반응형 축소 시 2열 → 1열
- 상단 툴바: 좌측 검색결과 건수, 우측 출력개수 셀렉트(10/20/50/100)
- 테이블: 전체 너비 사용, 고정 헤더
- 페이지네이션: 하단 중앙 배치

## 인터랙션

### 검색

1. 필터 조건 입력 후 `검색` 버튼 클릭 또는 Enter 키 입력
2. 입력된 조건 + product_category=SHIPPING + approval_status=APPROVED 필터로 API 호출
3. 결과를 테이블에 표시하고 검색결과 건수를 갱신
4. 페이지네이션은 1페이지로 초기화

### 초기화

1. `초기화` 버튼 클릭
2. 모든 필터를 기본값으로 되돌림
3. 자동으로 재검색하지 않음 (사용자가 검색 버튼을 다시 눌러야 함)

### 정렬

1. 정렬 가능 컬럼(등록일)의 헤더 클릭
2. asc → desc → 기본 순서로 토글
3. 정렬 변경 시 현재 필터 조건 유지한 채 재조회

### 행 클릭 → 수정 폼 이동

1. 테이블 행의 상품명 링크 클릭
2. 배송상품 등록/수정 폼([BO-PDM-020](./BO-PDM-020_배송상품-등록수정-폼.md))의 수정 모드로 이동
3. URL 파라미터로 `product_id` 전달
4. APPROVED 상태이므로 상품명, 판매상태, 판매기간만 편집 가능

### 페이지네이션

1. 페이지 번호 또는 이전/다음 버튼 클릭
2. 현재 필터 조건 유지한 채 해당 페이지 데이터 조회
3. 스크롤 위치를 테이블 상단으로 이동

### 출력개수 변경

1. 출력개수 셀렉트에서 값 변경 (10/20/50/100)
2. 1페이지로 초기화하여 재조회

## 상태 처리

| 상태 | 설명 | UI 표현 |
|------|------|---------|
| 초기 | 페이지 최초 진입 | 기본 필터 조건(등록기간: 최근 1개월)으로 자동 검색 |
| 로딩 | API 호출 중 | 테이블 영역에 로딩 스피너 표시, 검색 버튼 비활성화 |
| 데이터 없음 | 조회 결과 0건 | 테이블 영역에 "검색 결과가 없습니다." 메시지 표시 |
| 조회 완료 | 데이터 정상 반환 | 테이블에 데이터 표시, 검색결과 건수 갱신 |
| 오류 | API 호출 실패 | 토스트 알림으로 오류 메시지 표시, 이전 데이터 유지 |
