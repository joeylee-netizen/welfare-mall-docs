# 배송상품 승인 목록 테이블

## 개요

BO 관리자가 배송형 상품의 승인대기 목록을 조회하고, 승인 또는 반려 처리하는 목록 컴포넌트이다. [BO-PDM-001](../01-policies/BO-PDM-001_상품-관리-정책.md)의 메뉴 구조 중 **상품 관리 > 상품 등록/승인 관리 > 배송상품 승인 목록**에 해당한다. 승인 시 상품코드가 자동 부여되며, 반려 시 반려사유 입력이 필수이다.

- 조회 대상: product_category = `SHIPPING` (배송형) 상품만 표시
- product_type 범위: `GENERAL_SHIPPING`, `INSTALLATION`

## 승인/반려 모달

### 승인 확인 모달

| 항목 | 내용 |
|------|------|
| 트리거 | 개별 행의 승인 버튼 또는 일괄 승인 버튼 클릭 |
| 제목 | 배송상품 승인 확인 |
| 본문 | "선택한 N건의 배송상품을 승인하시겠습니까? 승인 시 상품코드가 부여됩니다." |
| 버튼 | `취소`, `승인` (Primary) |
| 처리 | 승인 클릭 시 API 호출 → approval_status를 APPROVED로 변경 + product_code 자동 부여 |

### 반려 사유 입력 모달

| 항목 | 내용 |
|------|------|
| 트리거 | 개별 행의 반려 버튼 또는 **일괄 반려** 버튼 클릭 |
| 제목 | 배송상품 승인 반려 |
| 본문 | 반려 대상 상품 정보 (요청코드, 상품명, 브랜드) 표시. 일괄 반려 시 N건 표시 |
| 입력 | 반려사유 Textarea (필수, 최대 500자) |
| 버튼 | `취소`, `반려` (Danger) |
| 검증 | 반려사유 미입력 시 "반려사유를 입력해 주세요." 인라인 오류 |
| 처리 | 반려 클릭 시 API 호출 → approval_status를 REJECTED로 변경 + 이력 기록 |

## 인터랙션

### 검색

1. 필터 조건 입력 후 `검색` 버튼 클릭 또는 Enter 키 입력
2. 입력된 조건 + product_category=SHIPPING 필터로 API 호출
3. 결과를 테이블에 표시하고 검색결과 건수를 갱신
4. 체크박스 선택 상태 초기화

### 행 선택 (체크박스)

1. 개별 행의 체크박스 클릭 시 해당 행 선택/해제
2. 헤더 전체 선택 체크박스 클릭 시 현재 페이지 전체 선택/해제
3. `PENDING` 상태가 아닌 행의 체크박스도 선택 가능하나, 승인/반려 버튼은 PENDING 행만 처리
4. 1건 이상 선택 시 `일괄 승인`, `일괄 반려` 버튼 활성화

### 일괄 승인

1. 체크박스로 승인 대상 행 선택 (1건 이상)
2. `일괄 승인` 버튼 클릭
3. 승인 확인 모달 표시 (선택 건수 포함)
4. `승인` 버튼 클릭 시 선택된 전체 상품 일괄 승인 API 호출
5. 처리 완료 후 목록 재조회 + 성공 토스트 표시

### 일괄 반려

1. 체크박스로 반려 대상 행 선택 (1건 이상, PENDING 상태만 대상)
2. `일괄 반려` 버튼 클릭
3. 반려 사유 입력 모달 표시 (선택 건수 포함)
4. 반려사유 입력 후 `반려` 버튼 클릭
5. 일괄 반려 API([BO-PDM-03B](../04-actions/BO-PDM-03B_상품-일괄반려.md)) 호출
6. 처리 완료 후 목록 재조회 + 성공 토스트 표시

### 개별 승인

1. 테이블 행 우측의 `승인` 버튼 클릭
2. 승인 확인 모달 표시 (1건)
3. `승인` 버튼 클릭 시 API 호출
4. 처리 완료 후 해당 행의 승인상태 갱신 + 성공 토스트 표시

### 개별 반려

1. 테이블 행 우측의 `반려` 버튼 클릭
2. 반려 사유 입력 모달 표시
3. 반려사유 입력 후 `반려` 버튼 클릭
4. 반려사유 미입력 시 인라인 오류 메시지 표시
5. 검증 통과 시 API 호출
6. 처리 완료 후 해당 행의 승인상태 갱신 + 성공 토스트 표시

## 상태 처리

| 상태 | 설명 | UI 표현 |
|------|------|---------|
| 초기 | 페이지 최초 진입 | 기본 필터 조건으로 자동 검색 |
| 로딩 | API 호출 중 | 테이블 영역에 로딩 스피너(skeleton) 표시, 검색/승인/반려 버튼 비활성화 |
| 데이터 없음 | 조회 결과 0건 | "조회 결과가 없습니다." 메시지 + [필터 초기화] 버튼 |
| 조회 완료 | 데이터 정상 반환 | 테이블에 데이터 표시, PENDING 행만 승인/반려 버튼 활성화 |
| 승인 처리 중 | 승인 API 호출 중 | 모달의 승인 버튼 로딩 상태, 닫기 불가 |
| 반려 처리 중 | 반려 API 호출 중 | 모달의 반려 버튼 로딩 상태, 닫기 불가 |
| 처리 완료 | 승인/반려 성공 | 모달 닫힘, 목록 재조회(필터 조건 유지), 성공 토스트 표시, 체크박스 선택 초기화 |
| 오류 (400) | 요청 파라미터 오류 | 토스트: "입력 조건을 확인해 주세요." |
| 오류 (409) | 상태 충돌 | 토스트: "상품 상태가 변경되었습니다. 목록을 갱신합니다." + 자동 재조회 |
| 오류 (500) | 서버 오류 | 토스트: "서버 오류가 발생했습니다. 잠시 후 다시 시도해 주세요." + [재시도] 버튼 |
| 네트워크 오류 | 연결 실패 | 토스트: "네트워크 연결을 확인해 주세요." |
