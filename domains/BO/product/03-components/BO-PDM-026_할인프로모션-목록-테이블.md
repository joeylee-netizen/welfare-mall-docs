# 할인프로모션 목록 테이블

## 개요

BO 관리자가 할인프로모션을 조회·검색·관리하는 목록 화면 컴포넌트이다. [BO-PDM-002](../01-policies/BO-PDM-002_할인프로모션-정책.md)의 할인프로모션 정책에 따라 프로모션 3종(MZ_VENDOR/MZ_PLATFORM/VENDOR)을 검색하고, 중지·삭제 등의 일괄 작업을 수행할 수 있다.

- 조회 대상: 전체 상태의 프로모션 (DELETED 제외)
- 조회 버튼 클릭 시 할인프로모션 등록 화면([BO-PDM-049](../05-wireframes/BO-PDM-049_할인프로모션-등록-화면.md))으로 이동 (수정 모드)

---

## 검색 필터 구성 (6개)

| No | 필터명 | 데이터 필드 | 입력 유형 | 기본값 | 비고 |
|----|--------|------------|-----------|--------|------|
| 1 | 프로모션구분 | promotion_type | 체크박스 | 전체 | 전체/메가존(판매사부담)/메가존(복지몰부담)/판매사 |
| 2 | 판매사 | vendor_id | 조회 팝업 | - | 팝업 선택 → 판매사명 출력 |
| 3 | 진행상태 | status | 체크박스 | 전체 | 전체/임시저장/진행중/중지/종료 |
| 4 | 쿠폰적용여부 | coupon_applicable | 체크박스 | 전체 | 전체/적용 가능/적용 불가 |
| 5 | 기간 | created_at / start_date / end_date | Select + DateRange + Radio | 등록일, 최근 1개월 | 기간유형: 등록일/프로모션 시작일/프로모션 종료일. 퀵선택: 오늘/7일/1개월(기본)/3개월/1년 |
| 6 | 검색어 | keyword | Select + Text | 프로모션명 | 프로모션명/프로모션코드/상품코드 |

- 필터 영역은 접힘/펼침 가능하며, 기본 펼침 상태이다.
- `검색` 버튼 클릭 또는 Enter 키로 조회를 실행한다.
- `초기화` 버튼 클릭 시 모든 필터를 기본값으로 되돌린다.

## 레이아웃

```
┌─────────────────────────────────────────────────┐
│ 검색 필터 영역 (접힘/펼침, 6개 항목)               │
│ 프로모션구분(체크박스 4종) | 판매사(팝업)           │
│ 진행상태(체크박스 5종) | 쿠폰적용여부(체크박스)      │
│ 기간 (드롭박스+피커+퀵선택)                        │
│ 검색어 (드롭박스 + 텍스트)                         │
│               [초기화] [검색]                      │
├─────────────────────────────────────────────────┤
│ 상단 툴바: 검색결과 N건 | 출력건수  [등록][중지][삭제]│
├─────────────────────────────────────────────────┤
│ 할인프로모션 목록 테이블 (13컬럼)                   │
│ [v]| No | ID | 프로모션명 | 구분 | ... | [조회]   │
│ ─────────────────────────────────────────────── │
│ [v]|  1 | PM001 | 봄맞이 할인 | ... | [조회]      │
│ ...                                              │
├─────────────────────────────────────────────────┤
│ 페이지네이션: [<<] [<] 1 2 3 4 5 [>] [>>]         │
└─────────────────────────────────────────────────┘
```

- 필터 영역: 테이블형 2열 그리드, 접힘/펼침
- 상단 툴바: 좌측 검색결과 건수 + 출력건수 셀렉트, 우측 버튼 그룹
- 테이블: 전체 너비 사용, 고정 헤더
- 페이지네이션: 하단 중앙 배치

## 인터랙션

### 검색

1. 필터 조건 입력 후 `검색` 버튼 클릭 또는 Enter 키 입력
2. 입력된 조건으로 API 호출
3. 결과를 테이블에 표시하고 검색결과 건수를 갱신
4. 페이지네이션은 1페이지로 초기화

### 초기화

1. `초기화` 버튼 클릭
2. 모든 필터를 기본값으로 되돌림
3. 자동으로 재검색하지 않음

### 일괄 중지

1. 체크박스로 ACTIVE 상태 프로모션 선택
2. `중지` 버튼 클릭
3. 확인 모달: "선택한 프로모션을 중지하시겠습니까?"
4. 확인 시 일괄 중지 처리 (ACTIVE → PAUSED)
5. FO 할인 즉시 해제

### 일괄 삭제

1. 체크박스로 DRAFT/PAUSED/ENDED 상태 프로모션 선택
2. `삭제` 버튼 클릭
3. 확인 모달: "선택한 프로모션을 삭제하시겠습니까?"
4. 확인 시 일괄 삭제 처리 (soft delete)

### 조회 버튼 → 수정 화면 이동

1. 테이블 행의 `조회` 버튼 클릭
2. 할인프로모션 등록 화면([BO-PDM-049](../05-wireframes/BO-PDM-049_할인프로모션-등록-화면.md))으로 이동 (수정 모드)
3. URL 파라미터로 `promotion_id` 전달

### 페이지네이션

1. 페이지 번호 또는 이전/다음 버튼 클릭
2. 현재 필터 조건 유지한 채 해당 페이지 데이터 조회
3. 스크롤 위치를 테이블 상단으로 이동

### 출력개수 변경

1. 출력개수 셀렉트에서 값 변경 (20/50/100)
2. 1페이지로 초기화하여 재조회

## 상태 처리

| 상태 | 설명 | UI 표현 |
|------|------|---------|
| 초기 | 페이지 최초 진입 | 기본 필터 조건으로 자동 검색 |
| 로딩 | API 호출 중 | 테이블 영역에 로딩 스피너 표시, 검색 버튼 비활성화 |
| 데이터 없음 | 조회 결과 0건 | "조회 결과가 없습니다." 메시지 + [필터 초기화] 버튼 |
| 조회 완료 | 데이터 정상 반환 | 테이블에 데이터 표시, 검색결과 건수 갱신 |
| 오류 (400) | 요청 파라미터 오류 | 토스트: "입력 조건을 확인해 주세요." |
| 오류 (500) | 서버 오류 | 토스트: "서버 오류가 발생했습니다. 잠시 후 다시 시도해 주세요." + [재시도] 버튼 |
| 네트워크 오류 | 연결 실패 | 토스트: "네트워크 연결을 확인해 주세요." |
