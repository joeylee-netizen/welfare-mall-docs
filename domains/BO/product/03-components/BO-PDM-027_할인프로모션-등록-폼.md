# 할인프로모션 등록 폼

## 개요

BO 관리자가 할인프로모션을 **신규 등록**하거나 **기존 프로모션을 수정**하는 폼 컴포넌트이다. [BO-PDM-002](../01-policies/BO-PDM-002_할인프로모션-정책.md)의 할인프로모션 정책에 따라 프로모션 정보를 입력하고, 대상 상품을 선택한다.

- **등록 모드:** 목록 화면에서 `등록` 버튼 클릭 시, 빈 폼으로 신규 프로모션 입력
- **수정 모드:** 목록 화면에서 프로모션명 클릭 시, 기존 데이터 로드

---

## 모드 제어

| 조건 | 모드 | 편집 범위 | 헤더 타이틀 |
|------|------|----------|------------|
| promotion_id 없음 | 등록 모드 | 모든 필드 입력 가능 | 할인프로모션 등록 |
| promotion_id 있음 + DRAFT | 수정 모드 | 전체 편집 가능 | 할인프로모션 수정 |
| promotion_id 있음 + ACTIVE | 수정 모드 | 종료일시, 쿠폰적용여부만 수정 | 할인프로모션 수정 |
| promotion_id 있음 + PAUSED/ENDED | 조회 모드 | 읽기전용 | 할인프로모션 상세 |

## 인터랙션

### 등록 — 저장

1. 모든 필수 필드 입력 후 `저장` 버튼 클릭
2. 클라이언트 검증 수행:
   - 프로모션명: 빈 값 불가, 100자 이내
   - 프로모션구분: 미선택 불가
   - 할인금액: 0 초과 정수
   - 프로모션기간: 시작일·종료일 필수, 종료일 > 시작일
   - 대상상품: 1건 이상 필수
3. 검증 통과 시 확인 모달: "할인프로모션을 등록하시겠습니까?"
4. 확인 시 API 호출 → 승인완료 상품 체크 → 기간 중복 체크 → 프로모션코드 자동발급 → DB 저장
5. 저장 완료 후 목록 화면으로 이동 + 성공 토스트

### 수정 — 저장

1. 수정 후 `저장` 버튼 클릭
2. 클라이언트 검증 수행 (모드별 편집 범위에 해당하는 필드만)
3. 확인 모달: "수정 사항을 저장하시겠습니까?"
4. 확인 시 API 호출하여 저장
5. 저장 완료 시 성공 토스트 + 데이터 갱신

### 상품 추가

1. `상품 추가` 버튼 클릭
2. 상품 검색 팝업(`productPopup049`) 표시
3. 상품코드/상품명으로 검색
4. 체크박스로 복수 상품 선택
5. `추가` 버튼 클릭 시 대상상품 서브테이블에 추가
6. 이미 추가된 상품은 중복 추가 불가

### 상품 삭제

1. 서브테이블 행의 X 버튼 클릭
2. 해당 상품을 대상상품 목록에서 제거
3. 별도 확인 없이 즉시 제거 (저장 전까지 DB 미반영)

### 취소

1. `취소` 버튼 클릭
2. 변경사항이 있는 경우: "저장하지 않은 변경 사항이 있습니다. 이동하시겠습니까?" 확인 모달
3. 확인 시 할인프로모션 목록([BO-PDM-048](../05-wireframes/BO-PDM-048_할인프로모션-목록-화면.md))으로 이동

## 상태 처리

| 상태 | 설명 | UI 표현 |
|------|------|---------|
| 등록 초기 | 빈 폼 | 모든 필드 편집 가능, 저장 버튼 표시 |
| 수정 초기 | 데이터 로드 | 상태에 따른 편집 범위 적용 |
| 로딩 | API 호출 중 | 폼 비활성화, 버튼 로딩 상태 |
| 저장 완료 | 저장 성공 | 성공 토스트, 목록 화면 이동 |
| 검증 실패 | 필수 필드 미입력 등 | 필드별 인라인 오류 메시지 |
| 기간 중복 | 동일 상품 기간 중복 | 토스트: "동일 상품에 기간이 중복되는 프로모션이 존재합니다." |
| 미승인 상품 | 대상 상품 중 미승인 건 존재 | 토스트: "승인완료되지 않은 상품이 포함되어 있습니다." |
| 오류 | API 호출 실패 | 오류 토스트 표시 |
