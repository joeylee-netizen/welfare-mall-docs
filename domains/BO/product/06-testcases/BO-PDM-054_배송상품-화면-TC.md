# 배송상품 화면 테스트케이스

## 테스트 개요

배송상품 4개 화면(목록→승인목록→등록수정→상세) 간 전체 플로우 E2E 검증.
[BO-PDM-040](../05-wireframes/BO-PDM-040_배송상품-목록-화면.md)(목록),
[BO-PDM-042](../05-wireframes/BO-PDM-042_배송상품-승인목록-화면.md)(승인목록),
[BO-PDM-044](../05-wireframes/BO-PDM-044_배송상품-등록수정-화면.md)(등록수정),
[BO-PDM-046](../05-wireframes/BO-PDM-046_배송상품-상세-화면.md)(상세) 와이어프레임 기반.

### 범위

- 화면 간 네비게이션 흐름
- 등록 → 승인요청 → 승인 → 목록 노출 전체 라이프사이클
- 7개 탭(기본정보·전시정보·판매정보·옵션/재고·배송정보·상세정보·상품정보제공고시) 전환
- 모드 전환 (등록→수정→조회)

### 전제 조건

- BO 관리자 로그인 (등록+승인 권한)
- 카테고리·브랜드·판매사·MD 마스터 데이터 준비

---

## 테스트 케이스

### TC-001: 배송상품 등록 → 수정 모드 전환 E2E

| 항목 | 내용 |
|------|------|
| 구분 | 정상 |
| 사전 조건 | 배송상품 등록 화면 진입 (등록 모드) |
| 테스트 절차 | 1. 기본정보 탭에서 상품유형 "일반배송" 선택 → 2. 각 탭을 순서대로 이동하며 필수 필드 입력 (7개 탭) → 3. [저장] 클릭 → 4. 모드 전환 확인 |
| 기대 결과 | 저장 성공, 현재 화면 유지, 수정 모드 전환, 요청코드 표시, [승인요청] 버튼 활성화 |
| 우선순위 | 상 |

### TC-002: 승인요청 → 조회 모드 전환

| 항목 | 내용 |
|------|------|
| 구분 | 정상 |
| 사전 조건 | TC-001 이후 수정 모드 상태 |
| 테스트 절차 | 1. [승인요청] 클릭 → 2. 확인 모달 [확인] |
| 기대 결과 | PENDING 전환, 화면 조회 모드(모든 필드 읽기전용), [승인철회] 버튼만 활성 |
| 우선순위 | 상 |

### TC-003: 승인목록에서 등록수정 화면 이동 (새 탭)

| 항목 | 내용 |
|------|------|
| 구분 | 정상 |
| 사전 조건 | TC-002에서 PENDING된 상품 |
| 테스트 절차 | 1. 배송상품 승인목록(042) 진입 → 2. 해당 상품 요청코드 링크 클릭 |
| 기대 결과 | 새 탭에서 등록수정(044) 화면 열림, 조회 모드(읽기전용) |
| 우선순위 | 중 |

### TC-004: 승인 → 상품코드 발번 → 목록 노출

| 항목 | 내용 |
|------|------|
| 구분 | 정상 |
| 사전 조건 | PENDING 상태 배송상품 |
| 테스트 절차 | 1. 승인목록(042)에서 상품 체크 → 2. [승인] → 3. 확인 → 4. 배송상품 목록(040) 이동 |
| 기대 결과 | APPROVED 전환, 상품코드 채번, 배송상품 목록(040)에서 해당 상품 조회 가능 |
| 우선순위 | 상 |

### TC-005: 목록에서 상세 화면 이동

| 항목 | 내용 |
|------|------|
| 구분 | 정상 |
| 사전 조건 | APPROVED 배송상품이 목록(040)에 노출 |
| 테스트 절차 | 1. 배송상품 목록(040) → 2. 상품명 링크 클릭 |
| 기대 결과 | 배송상품 상세(046) 화면 이동, 7개 탭 데이터 표시, APPROVED 상태이므로 제한 편집 모드 |
| 우선순위 | 상 |

### TC-006: 상세 화면 — APPROVED 제한 편집 후 저장

| 항목 | 내용 |
|------|------|
| 구분 | 정상 |
| 사전 조건 | TC-005 상세 화면 진입 |
| 테스트 절차 | 1. 상품명 변경 → 2. 판매상태 변경 → 3. [저장] 클릭 |
| 기대 결과 | 200 OK, FO 즉시 반영 토스트, 미리보기 버튼 활성화 |
| 우선순위 | 중 |

### TC-007: 7개 탭 전환 검증

| 항목 | 내용 |
|------|------|
| 구분 | 정상 |
| 사전 조건 | 등록수정(044) 화면 진입 |
| 테스트 절차 | 1. 기본정보 → 전시정보 → 판매정보 → 옵션/재고 → 배송정보 → 상세정보 → 상품정보제공고시 순서대로 탭 클릭 |
| 기대 결과 | 각 탭 콘텐츠 정상 로드, 입력 데이터 유지 (탭 전환 시 소실 없음) |
| 우선순위 | 상 |

### TC-008: 배송정보 탭 — 출고지/반품/교환 3영역

| 항목 | 내용 |

| 기대 결과 | 3영역 데이터 각각 저장, 연동 데이터 자동 설정 |
| 우선순위 | 중 |

### TC-009: 이미지 업로드 — 최대 5개 + 대표 자동 설정

|------|------|

| 테스트 절차 | 1. 이미지 5개 업로드 → 2. 첫 이미지 대표 설정 확인 → 3. 6번째 이미지 업로드 시도 |

| 우선순위 | 중 |
