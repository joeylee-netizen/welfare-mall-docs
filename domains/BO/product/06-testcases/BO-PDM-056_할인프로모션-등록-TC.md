# 할인프로모션 등록 테스트케이스

## 테스트 개요

할인프로모션 등록·수정 기능 검증.
[BO-PDM-002](../01-policies/BO-PDM-002_할인프로모션-정책.md) 정책,
[BO-PDM-03C](../04-actions/BO-PDM-03C_할인프로모션-등록.md)(등록),
[BO-PDM-03D](../04-actions/BO-PDM-03D_할인프로모션-수정.md)(수정) 액션,
[BO-PDM-049](../05-wireframes/BO-PDM-049_할인프로모션-등록-화면.md) 와이어프레임 기반.

### 범위

- 등록 폼 필수값 검증 (프로모션명·구분·판매사·할인금액·기간·대상상품)
- 기간 중복 검증, 대상상품 APPROVED 조건
- 쿠폰 적용 여부, 할인금액 제약
- 상태별 수정 범위 (DRAFT: 전체, ACTIVE: 종료일시+쿠폰만)

### 전제 조건

- BO 관리자 로그인
- APPROVED 상태 상품 사전 등록
- 기존 프로모션 데이터(기간 중복 검증용)

---

## 테스트 케이스

### TC-001: 프로모션 정상 등록 (전체 필드)

| 항목 | 내용 |
|------|------|
| 구분 | 정상 |
| 사전 조건 | 등록 화면(049) 진입, APPROVED 상품 존재 |
| 테스트 절차 | 1. 프로모션명 입력 → 2. 프로모션구분 "MZ판매사부담" 선택 → 3. 판매사 팝업으로 선택 → 4. 할인금액 입력 → 5. 기간 설정 → 6. 대상상품 추가(팝업) → 7. 쿠폰적용여부 ON → 8. [저장] 클릭 |
| 기대 결과 | 등록 성공, DRAFT 상태 생성, 프로모션코드 자동 발번, 목록(048)으로 이동 |
| 우선순위 | 상 |
