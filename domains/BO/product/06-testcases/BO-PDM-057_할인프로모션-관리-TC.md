# 할인프로모션 관리 테스트케이스

## 테스트 개요

할인프로모션 목록 조회·중지·삭제 기능의 UI 검증.
[BO-PDM-002](../01-policies/BO-PDM-002_할인프로모션-정책.md) 정책 §9(상태전이),
[BO-PDM-03E](../04-actions/BO-PDM-03E_할인프로모션-중지-삭제.md)(중지·삭제),
[BO-PDM-03F](../04-actions/BO-PDM-03F_할인프로모션-목록-조회.md)(조회),
[BO-PDM-048](../05-wireframes/BO-PDM-048_할인프로모션-목록-화면.md)(목록) 와이어프레임 기반.

### 범위

- 목록 검색 필터 6개 동작 (프로모션구분·판매사·진행상태·쿠폰적용·기간·검색어)
- 상태 전이: ACTIVE→PAUSED, PAUSED→ACTIVE, DRAFT/PAUSED/ENDED→DELETED
- ACTIVE 직접 삭제 차단
- 부분 성공 처리

### 전제 조건

- BO 관리자 로그인
- 다양한 상태(DRAFT/ACTIVE/PAUSED/ENDED)의 프로모션 사전 등록
