# 상품 수정·삭제 테스트케이스

## 테스트 개요

상품 수정(`PUT /api/v1/products/{id}`), 삭제(`DELETE /api/v1/products/{id}`),
임시저장(`POST|PATCH /api/v1/products/temp-save`) API의 기능 검증.
[BO-PDM-001](../01-policies/BO-PDM-001_상품-등록-정책.md) 정책 §5(수정)·§6(삭제)와
관련 액션 문서를 기반으로 도출한다.

### 범위

- 승인상태별 편집 범위 검증 (REGISTERING/WITHDRAWN/REJECTED: 전체, APPROVED: 제한, PENDING: 불가)
- 삭제 가능 상태 검증 (REGISTERING/WITHDRAWN만 허용)
- 임시저장 기능 (필수 필드 검증 생략, is_temp_saved 플래그)

### 전제 조건

- BO 관리자 로그인 완료
- 각 승인상태의 테스트 상품 사전 등록
