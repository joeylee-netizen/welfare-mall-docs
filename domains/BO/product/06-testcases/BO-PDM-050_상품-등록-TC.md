# 상품 등록 테스트케이스

## 테스트 개요

상품 등록 API(`POST /api/v1/products`)의 기능 검증을 위한 테스트케이스.
[BO-PDM-001](../01-policies/BO-PDM-001_상품-등록-정책.md) 정책 §4(등록) 규칙과
[BO-PDM-030](../04-actions/BO-PDM-030_상품-등록-API.md) 액션 명세를 기반으로 도출한다.

### 범위

- 배송형(일반/설치) 및 티켓형(e쿠폰/예약) 4개 상품유형 등록
- 필수 필드 검증, 경계값 검증, 에러코드 검증
- 등록 후 상태 확인 (REGISTERING, 요청코드 발번)

### 전제 조건

- BO 관리자 로그인 완료 (상품 등록 권한 보유)
- 유효한 브랜드 ID, 판매사 ID, 카테고리 데이터 사전 등록

---

## 테스트 케이스

### TC-001: 배송형 일반 상품 정상 등록

| 항목 | 내용 |
|------|------|
| 구분 | 정상 |
| 사전 조건 | 유효한 브랜드 ID 존재, 배송 정보 입력 가능 |
| 테스트 절차 | 1. 배송상품 등록 화면 진입 → 2. 상품유형 "일반배송" 선택 → 3. 상품명·카테고리·브랜드·세금구분·판매상태·전시여부·노출채널·배송정보 등 필수 필드 전부 입력 → 4. [저장] 클릭 |
| 기대 결과 | 201 Created, `approval_status = REGISTERING`, 요청코드(`request_code`) 자동 발번, 수정 모드로 전환 |
| 우선순위 | 상 |
