# 상품 승인 테스트케이스

## 테스트 개요

상품 승인 프로세스 전체(승인요청·철회·개별승인·일괄승인·개별반려·일괄반려)의 기능 검증.
[BO-PDM-001](../01-policies/BO-PDM-001_상품-등록-정책.md) 정책 §7(승인)과
[BO-PDM-033](../04-actions/BO-PDM-033_상품-승인요청-API.md)~[BO-PDM-03B](../04-actions/BO-PDM-03B_상품-일괄반려-API.md) 액션 명세 기반.

### 범위

- 승인요청/재승인요청, 승인철회
- 개별 승인·반려, 일괄 승인·반려
- 상태 전이 검증 및 에러코드 검증
- 승인 시 상품코드 자동 채번 확인

### 전제 조건

- BO 관리자 로그인 (승인 권한 보유)
- 각 상태의 테스트 상품 사전 준비

---

## 테스트 케이스

### TC-001: 승인요청 — REGISTERING → PENDING

| 항목 | 내용 |
|------|------|
| 구분 | 정상 |
| 사전 조건 | REGISTERING 상태, 모든 필수 필드 입력 완료 |
| 테스트 절차 | 1. 등록수정 화면 → 2. [승인요청] 클릭 → 3. 확인 모달 [확인] |
| 기대 결과 | 200 OK, `PENDING` 전환, 화면 조회 모드(읽기전용) 전환 |
