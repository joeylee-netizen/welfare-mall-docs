BO-PDM-040 — 배송상품 목록 화면

메뉴 경로: 상품 관리 > 배송상품 관리 > 배송상품 목록

Route: /bo/products/delivery

관련 문서

  • 컴포넌트: BO-PDM-024 (배송상품 목록 테이블)
  • 액션: BO-PDM-038 (상품 목록 조회)

검색/필터 영역

  • 상품유형: 전체 / 일반상품 / 옵션상품
  • 판매상태: 전체 / 판매중 / 판매일시중지 / 일시품절 / 품절 / 판매종료
  • 브랜드: 셀렉트 (전체 + 개별)
  • 상품명: 키워드 검색 (LIKE)
  • 등록기간: 시작일 ~ 종료일

목록 테이블

  • 9컬럼: No, 상품코드, 요청코드, 상품명(링크), 상품유형, 판매상태(badge), 브랜드, 판매기간, 등록일
  • 상품명 클릭 → 상세/수정 화면 이동
  • 기본 정렬: 등록일 DESC
  • 출력건수: 20 / 50 / 100건 선택

판매상태 Badge

  • 판매중 SELLING
  • 판매일시중지 SALES_PAUSED
  • 일시품절 TEMP_OUT_OF_STOCK
  • 품절 OUT_OF_STOCK
  • 판매종료 SALES_ENDED
