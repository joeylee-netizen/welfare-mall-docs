BO-PDM-040 — 배송상품 목록 화면

메뉴 경로: 상품 관리 > 배송상품 관리 > 배송상품 목록

Route: /bo/products/delivery

진입 조건: BO 관리자 로그인 상태, 상품 조회 권한 보유

관련 문서

  • 컴포넌트: BO-PDM-024 (배송상품 목록 테이블)
  • 액션: BO-PDM-038 (상품 목록 조회)

화면 로드 동작

  • 페이지 진입 시 전체 조건 초기화 상태로 자동 조회 (trigger: load)
  • 기본 정렬: 등록일 DESC
  • 기본 출력건수: 20건

1. 검색/필터 영역 (10개 조건)

1-1. 카테고리 (최상단 배치)

  • UI: 셀렉트 4개 가로 배치 — [카테고리유형] [1차] [2차] [3차]
  • 카테고리유형: 표준카테고리(기본값) / 전시카테고리
  • 카테고리유형 변경 시 1차·2차·3차 옵션 목록 갱신 및 초기화
  • 1차 선택 시 2차 활성화, 2차 선택 시 3차 활성화 (순차 연동)
  • 상위 depth 변경 시 하위 depth 초기화 (전체로 리셋)
  • 미선택 시 "N차 전체"로 해당 depth 이하 전체 검색

1-2. 상품코드

  • UI: 텍스트 입력 (placeholder: PRD-YYYY-NNNN)
  • 완전 일치 검색 (exact match)
  • 미입력 시 전체

1-3. 요청코드

  • UI: 텍스트 입력 (placeholder: REQ-YYYY-NNNN)
  • 완전 일치 검색 (exact match)
  • 미입력 시 전체

1-4. 상품유형

  • UI: 셀렉트
  • 옵션: 전체(기본값) / 일반상품 / 옵션상품

1-5. 승인상태

  • UI: 셀렉트
  • 옵션: 전체(기본값) / 등록중(REGISTERING) / 승인대기(PENDING) / 승인완료(APPROVED) / 반려(REJECTED) / 승인철회(WITHDRAWN)

1-6. 판매상태

  • UI: 셀렉트
  • 옵션: 전체(기본값) / 판매중(SELLING) / 판매일시중지(SALES_PAUSED) / 일시품절(TEMP_OUT_OF_STOCK) / 품절(OUT_OF_STOCK) / 판매종료(SALES_ENDED)

1-7. 브랜드

  • UI: 셀렉트
  • 옵션: 전체(기본값) + DB에서 조회한 개별 브랜드 목록
  • 브랜드 목록은 페이지 로드 시 API 호출로 세팅

1-8. 상품명

  • UI: 텍스트 입력
  • 부분 일치 검색 (LIKE '%keyword%')
  • 최소 2자 이상 입력 권장 (미만 시 경고 없이 검색 허용)

1-9. 판매가

  • UI: 숫자 입력 2개 (최소 ~ 최대), 단위: 원
  • 최소만 입력: 해당 금액 이상 검색
  • 최대만 입력: 해당 금액 이하 검색
  • 양쪽 입력: 범위 검색 (최소 ≤ 판매가 ≤ 최대)
  • 최소 > 최대 입력 시 "최소 금액이 최대 금액보다 클 수 없습니다" 알림

1-10. 등록기간

  • UI: 날짜 선택 2개 (시작일 ~ 종료일)
  • 시작일만 입력: 해당일 이후 검색
  • 종료일만 입력: 해당일 이전 검색
  • 양쪽 입력: 기간 범위 검색
  • 시작일 > 종료일 입력 시 "시작일이 종료일보다 클 수 없습니다" 알림

버튼

  • [검색]: 현재 필터 조건으로 목록 재조회, 페이지 1로 초기화
  • [초기화]: 모든 필터 조건을 기본값으로 리셋 후 재조회

2. 상단 툴바

  • 좌측: "검색결과 N건" — 현재 필터 조건에 매칭되는 총 건수 표시
  • 우측: 출력건수 셀렉트 (20건(기본) / 50건 / 100건)
  • 출력건수 변경 시 페이지 1로 초기화 후 재조회

  • 페이지 변경 시 현재 필터 조건 유지한 채 해당 페이지 조회
  • 첫 페이지에서 [이전] 비활성, 마지막 페이지에서 [다음] 비활성
