상품정보제공고시

연동: 상품분류 선택 시 항목 자동 출력 (수정/추가/삭제 가능). 직접입력: 빈 상태에서 항목 직접 추가. 분류 변경 시 항목 초기화.

번호 항목 내용 추가/삭제

BO-PDM-047 — 티켓상품 상세 화면

메뉴 경로: 상품 관리 > 티켓상품 관리 > 티켓상품 목록 > 상품 상세

Route: /bo/products/ticket/:id

진입 흐름

  • 티켓상품 목록(BO-PDM-041)에서 상품명 클릭
  • 승인완료(APPROVED) 상품 대상
  • 목록 → 상세(편집) → 저장 플로우

기본정보 탭 — 편집 가능 폼 (5개 영역)

1.1 기본정보

  1. 외부연동 여부 — readonly. 시스템 자동 설정값
  2. 상품명 * — input text (full width)
    • 검증: 필수. 최대 100 bytes (한글 50자). 특수문자 허용
  3. 상품코드 — readonly. 승인완료 시 자동 부여(13자리)
  4. 판매사 상품코드 — input number. 판매사 자체 관리 코드(선택)
  5. 다국어 상품명 — input text (full width). 최대 100 bytes. 영문/다국어(선택)
  6. 판매사 — readonly input + [조회] 팝업
    • 팝업 선택 시 하위업체 select 자동 갱신
    • 수정불가: 승인완료 후 판매사 변경 불가
  7. 하위업체 — select. 판매사 선택 후 활성화
  8. 상품키워드 — input + [등록하기] → 태그(chip) 출력
    • 검증: 개별 키워드 한글 10자/20 bytes. 최대 10개
    • FO 검색 키워드로 활용

1.1-A 티켓정보 (티켓 전용)

  1. 상품유형 * — radio (일반티켓 / 예약티켓). 기본값: 일반티켓
    • 수정불가: 승인완료 후 수정불가
  2. 티켓 타입 * — radio (모바일티켓 / 바우처). 승인완료 후 수정불가
    • 발급정보 탭의 발급방법 필드와 연동
  3. 유효기간 * — checkbox "유효기간 없음" + date-range (시작 ~ 종료)
    • "유효기간 없음" 체크 시 날짜 비활성화
    • 승인완료 후 수정불가
  4. 패스 타입 — select (1일권/시즌권/연간권 등). 승인완료 후 수정불가
  5. 취소 가능일 — number input (일). 승인완료 후 수정불가
  6. 이용필수규칙 — textarea. 승인완료 후 수정불가
    • FO 상품 상세에 이용 안내로 노출

1.2 추가정보

  1. 상품리뷰 등록 — radio (가능/불가능). 기본값: 가능
  2. Q&A 등록 — radio (가능/불가능). 기본값: 가능
  3. 선물하기 — radio (가능/불가능). 기본값: 가능
  4. 최소 구매수량 — radio(사용안함/사용) + number input
    • 1회당 구매 가능한 최소 수량
  5. 최대 구매수량 — radio(사용안함/사용) + number input
    • 1회당 구매 가능한 최대 수량
  6. 특가 구매수량 — radio(사용안함/사용) + number input
    • 판매기간 동안 구매 가능한 수량
    • 연동: "사용" 선택 시 최소/최대 구매수량 자동 "사용안함" 처리

1.3 고객사 정보

  1. 노출 제외 고객사 — radio (미등록/등록). 기본값: 미등록
  2. 고객사 입력 — readonly input + [조회] + [등록]
  3. 등록 목록 — 태그(chip) 형태. × 클릭 삭제

1.4 등록정보 (readonly)

  1. 승인상태 — Badge 표시. 5종: 승인대기/승인요청/승인완료/반려/삭제
  2. 반려사유 — 반려 시에만 값 표시, 정상이면 "-"
  3. 등록자 / 등록일시 — 최초 등록 정보
  4. 승인자 / 승인일시 — 최종 승인 정보
  5. 수정자 / 수정일시 — 마지막 수정 정보

1.5 판매상태

  1. 판매상태 변경 — select 5종
    • 판매중 / 판매일시중지 / 판매종료 / 일시품절 / 품절
    • 일시품절: 재고 0인 상태가 6일 이상 지속 시 자동 전환
    • 품절: 재고 0인 상태가 7일 이상 지속 시 자동 전환
    • 전환 규칙: BO-PDM-001 정책 준용

저장 시 수정불가 항목

• 상품유형, 판매사 — 승인완료 후 변경 불가

전시정보 탭 — 편집 가능 폼 (6필드)

2.1 전시정보

  1. 전시여부 * — radio (전시 / 비전시). 기본값: 전시
  2. 노출채널 * — checkbox (전체 / PC / 모바일)
  3. 전시기간 * — date-range (시작일 ~ 종료일)
  4. 담당MD * — readonly input + [조회] 팝업
  5. 표준카테고리 * — 3단 select (대/중/소분류) + [등록]
    • 대분류: 숙박/레저/외식 등 티켓 카테고리
  6. 전시카테고리 * — 테이블 (대표 라디오 / 경로 / 삭제)

저장 시 수정불가 항목

판매정보 탭 — 편집 가능 폼 (5개 영역)

3.1 판매정보 등록

  1. 판매기간 * — checkbox "제한없음" + date-range
  2. 과세구분 * — radio 3종 (과세/면세/영세). 기본값: 과세
  3. 성인인증상품 * — radio (Yes/No). 기본값: No

3.2 가격정보

  1. 판매가(VAT포함) * — input number
  2. 상품 마진율 — checkbox + input number (%)
  3. 상품 마진 — readonly (자동계산)
  4. 계약 마진율 — readonly (PO 계약값)
  5. 계약 마진 — readonly (자동계산)
