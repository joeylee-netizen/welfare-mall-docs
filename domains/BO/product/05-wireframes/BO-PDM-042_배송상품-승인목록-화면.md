# 배송상품 승인목록 화면

## 수정 이력

| 버전 | 날짜 | 작성자 | 변경 내용 |
|------|------|--------|----------|
| v1.0 | 2026-04-13 | 기획자 | 초안 작성 |

## 화면 개요

배송상품의 승인 요청 목록을 조회하고, 개별/일괄 승인 및 반려 처리를 수행하는 화면이다. 기본 필터가 "승인대기"(PENDING)로 설정되어 처리 대기 항목을 우선 표시한다.

## 레이아웃

- **GNB**: 다크 헤더(#1a1a2e) — 로고, BO 관리자, 사용자 정보
- **LNB**: 확장형 사이드바 — 상품 관리 그룹 확장, "배송상품 승인 목록" 활성
- **Content**: 검색 필터 → 툴바 → 테이블 → 페이지네이션
- **모달**: 승인 확인 모달, 반려 사유 모달

## 구성 요소

### 검색/필터 영역

- 컴포넌트 참조: [BO-PDM-022](../03-components/BO-PDM-022_배송상품-승인-목록-테이블.md)
- 필터 항목:
  - 승인상태: 기본값 "승인대기"(PENDING) — 전체 / 승인대기 / 등록중 / 승인철회 / 승인완료 / 반려
  - 상품유형: 전체 / 일반상품 / 옵션상품
  - 상품명: 키워드 검색
  - 요청기간: 시작일 ~ 종료일

### 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 체크박스 | 일괄 처리용 선택 |
| No | 행 번호 |
| 요청코드 | REQ-YYYY-NNNN |
| 상품명 | 상품명 텍스트 |
| 상품유형 | 일반상품 / 옵션상품 |
| 브랜드 | 브랜드명 |
| 승인상태 | Badge (REGISTERING, PENDING, WITHDRAWN, APPROVED, REJECTED) |
| 요청일 | YYYY-MM-DD |
| 요청자 | 요청자명 |
| 관리 | PENDING: 승인/반려 버튼, 기타: 처리완료/철회됨 텍스트 |

### 상단 툴바

- 검색결과 N건 표시
- 일괄 승인 버튼: 체크된 PENDING 항목 일괄 승인

### 승인 확인 모달

- 안내 문구: "선택한 상품을 승인하시겠습니까?"
- 승인 후 판매 가능 상태 전환 안내
- 취소 / 승인 버튼
- 액션: [BO-PDM-035](../04-actions/BO-PDM-035_상품-승인.md), [BO-PDM-036](../04-actions/BO-PDM-036_상품-일괄승인.md)

### 반려 사유 모달

- 상품 정보 표시 (요청코드, 상품명)
- 반려 사유 Textarea (필수)
- 취소 / 반려 버튼
- 액션: [BO-PDM-037](../04-actions/BO-PDM-037_상품-반려.md)

## 기능 명세

- 액션 참조: [BO-PDM-039](../04-actions/BO-PDM-039_상품-승인목록-조회.md) (상품 승인목록 조회)
- 페이지 로드 시 승인대기 목록 자동 조회
- 전체 선택 체크박스: 현재 페이지 전체 행 선택/해제
- 개별 승인: 해당 행의 승인 버튼 → 승인 확인 모달
- 개별 반려: 해당 행의 반려 버튼 → 반려 사유 모달
- 일괄 승인: 체크된 항목 → 승인 확인 모달
