## 화면 개요

티켓상품을 등록하거나 수정하는 폼 화면이다. **7개 콘텐츠 탭**으로 구성되며, BO-PDM-047(티켓상품 상세)과 동일한 단일 UI 구조를 사용한다.

**핵심 흐름**: 등록/수정(BO-PDM-045) → 승인요청 → BO 승인 → 상품코드 발급 → 상품 목록([BO-PDM-041](./BO-PDM-041_티켓상품-목록-화면.md)) → 상세([BO-PDM-047](./BO-PDM-047_티켓상품-상세-화면.md))

## 진입 조건

| 진입점 | 설명 |
|--------|------|
| 티켓상품 목록(BO-PDM-041) → [등록] 버튼 | 신규 상품 등록 |
| 티켓상품 승인목록(BO-PDM-043) → 상품명 클릭 | 기존 상품 수정 |

## 레이아웃

- **GNB**: 다크 헤더(#1a1a2e) — 로고, BO 관리자, 사용자 정보
- **LNB**: 확장형 사이드바 — 상품 관리 그룹 확장, "티켓상품 등록/수정" 활성
- **Content**: 콘텐츠 탭(7개) → 탭 콘텐츠(카드 분리형) → 하단 버튼(취소/미리보기/저장)
- **영역 구분**: 각 `.form-section`이 카드(border + shadow + padding) 형태로 시각적 분리. 콘텐츠 영역 배경(`#f4f6f8`)과 카드 배경(`#fff`) 대비로 가독성 확보.
