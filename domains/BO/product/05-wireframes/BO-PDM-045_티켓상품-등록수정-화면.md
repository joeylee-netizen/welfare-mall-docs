# 티켓상품 등록수정 화면

## 수정 이력

| 버전 | 날짜 | 작성자 | 변경 내용 |
|------|------|--------|----------|
| v1.0 | 2026-04-13 | 기획자 | 초안 작성 |

## 화면 개요

티켓상품(쿠폰형/예약형)을 등록하거나 수정하는 폼 화면이다. 탭으로 모드를 전환하여 등록/수정(REGISTERING)/수정(APPROVED)/조회(PENDING) 4가지 상태를 시뮬레이션한다.

## 레이아웃

- **GNB**: 다크 헤더(#1a1a2e) — 로고, BO 관리자, 사용자 정보
- **LNB**: 확장형 사이드바 — 상품 관리 그룹 확장, "티켓상품 등록/수정" 활성
- **Content**: 탭(모드 전환) → 기본정보 → 티켓 정보 → 상태정보 → 승인 이력 → 하단 버튼

## 구성 요소

### 탭 (모드 전환 시뮬레이션)

- 컴포넌트 참조: [BO-PDM-021](../03-components/BO-PDM-021_티켓상품-등록수정-폼.md)

| 탭 | 모드 | 설명 |
|----|------|------|
| 등록 모드 | register | 신규 상품 등록 (상품코드/요청코드 자동 생성) |
| 수정(REGISTERING) | editReg | 미승인 상태 상품 수정 (삭제 가능) |
| 수정(APPROVED) | editApproved | 승인 완료 상품 수정 (판매상태 변경 가능) |
| 조회(PENDING) | viewPending | 승인대기 중 조회 전용 (폼 비활성) |

### 섹션 1: 기본정보

| 필드 | 타입 | 필수 | 비고 |
|------|------|------|------|
| 상품코드 | readonly | - | 자동 생성 (수정/조회 모드에서 표시) |
| 요청코드 | readonly | - | 자동 생성 (수정/조회 모드에서 표시) |
| 상품유형 | select | Y | 쿠폰형 / 예약형 |
| 판매사 | select | Y | 판매사 목록 |
| 상품명 | text | Y | 상품명 입력 |

### 섹션 2: 티켓 정보

| 필드 | 타입 | 필수 | 비고 |
|------|------|------|------|
| 티켓유형 | select | Y | 쿠폰형 / 예약형 |
| 유효기간 | text | Y | 예: 발급일로부터 90일 |
| 사용처 | text | Y | 사용처 입력 |
| 사용 가능 요일 | text | - | 예: 월~금 / 전체 |
| 이용 안내 | textarea | - | 티켓 이용 관련 안내 |
| 예약 안내 | textarea | - | 예약형 상품 예약 방법 |

### 섹션 3: 상태정보

| 필드 | 타입 | 필수 | 비고 |
|------|------|------|------|
| 승인상태 | badge | - | 모드별 자동 표시 (REGISTERING/APPROVED/PENDING) |
| 판매상태 | select | - | 판매중 / 판매일시중지 / 판매종료 |
| 판매 시작일 | date | Y | 판매 시작일 |
| 판매 종료일 | date | Y | 판매 종료일 |

### 섹션 4: 승인 이력

- 수정/조회 모드에서만 표시
- 테이블: No, 요청일, 처리일, 처리자, 처리상태(badge), 비고

### 하단 버튼 (모드별)

| 모드 | 버튼 구성 |
|------|----------|
| 등록 | 목록 · 임시저장 · 저장 · 승인요청 |
| 수정(REGISTERING) | 목록 · 저장 · 삭제 · 승인요청 |
| 수정(APPROVED) | 목록 · 저장 · 판매일시중지 · 판매종료 |
| 조회(PENDING) | 목록 · 승인철회 |
