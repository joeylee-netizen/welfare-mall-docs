BO-PDM-041 — 티켓상품 목록 화면

메뉴 경로: 상품 관리 > 티켓상품 관리 > 티켓상품 목록

Route: /bo/products/ticket

진입 조건: BO 관리자 로그인 상태, 상품 조회 권한 보유

관련 문서: BO-PDM-025 (컴포넌트), BO-PDM-038 (액션)

페이지 진입 시 전체 조건 초기화 상태로 자동 조회 (trigger: load) · 기본 정렬: 상품등록일 DESC · 기본 출력건수: 20건

1 카테고리

UI: 셀렉트 4개 가로 배치 — [카테고리유형] [1차] [2차] [3차]

  • 카테고리유형: 표준카테고리(기본값) / 전시카테고리
  • 카테고리유형 변경 시 하위 1·2·3차 옵션 목록 갱신 및 초기화
  • 순차 연동: 1차 선택 → 2차 활성화, 2차 선택 → 3차 활성화
  • 상위 depth 변경 시 하위 depth "N차 전체"로 리셋
  • 미선택 시 해당 depth 이하 전체 검색
  • 1차 옵션: 숙박 / 여행 / 문화 / 레저 / 외식 / 뷰티 / 교육
정책: 카테고리 데이터는 카테고리 관리 화면에서 관리되며, 최대 3depth까지 지원한다. 표준/전시 카테고리는 독립 트리 구조.
2 판매사

UI: 텍스트(readonly) + [조회] 버튼 + 하위업체 드롭박스

  • [조회] 클릭 → 판매사 조회 팝업(15) 호출
  • 팝업에서 선택 완료 시 텍스트 필드에 판매사명 반영
  • 판매사 선택 후 → 우측 하위업체 드롭박스 활성화
  • 판매사 미선택 시 하위업체 드롭박스 disabled 유지
  • 하위업체 드롭박스: "하위업체 전체"(기본값) + 해당 판매사의 하위업체 목록
정책: 판매사는 판매사 관리 메뉴에서 등록·관리. 하위업체는 판매사에 종속되며, 판매사 1건에 N개 하위업체 매핑 가능.
3 MD

UI: 텍스트(readonly) + [조회] 버튼

  • [조회] 클릭 → MD 조회 팝업(16) 호출
  • 팝업에서 선택 완료 시 텍스트 필드에 MD 담당자명 반영
  • 미선택 시 전체 MD 대상 검색
정책: MD는 BO 관리자 중 상품 담당 역할자. 상품 등록 시 MD 필수 지정. 운영 관리 > 담당자 관리에서 MD 목록 관리.
4 외부연동 여부

UI: 체크박스 그룹

  • 옵션: 전체(기본 체크) / 직접등록 / 외부연동
  • "전체" 체크 시 → 개별 항목 모두 해제
  • 개별 항목 체크 시 → "전체" 자동 해제
  • 모든 개별 항목 해제 시 → "전체" 자동 체크 (빈 선택 방지)
  • 복수 선택 가능 (직접등록 + 외부연동 = 전체와 동일)
정책: 직접등록은 BO에서 수동 등록한 상품, 외부연동은 API/피드로 자동 연동된 상품. 외부연동 상품은 일부 필드 수정 제한.
5 기간 조회

UI: 기간유형 셀렉트 + 시작일~종료일 데이트피커 + 퀵선택 라디오

  • 기간유형: 상품등록일(기본값) / 최종수정일
  • 퀵선택 라디오: 오늘 / 최근 7일(기본) / 1개월 / 3개월 / 1년
  • 라디오 선택 시 시작일·종료일 자동 계산 (종료일 = 오늘 기준)
  • 데이트피커 직접 수정 시 퀵선택 라디오 선택 해제
  • 시작일 > 종료일 입력 시 "시작일이 종료일보다 클 수 없습니다" 알림
정책: 기간 검색은 필수. 페이지 로드 시 최근 7일이 기본 적용되어 초기 조회 범위를 제한한다.
6 상품유형

UI: 체크박스 그룹

  • 옵션: 전체(기본 체크) / 일반티켓 / 예약티켓
  • 체크박스 "전체" 토글 로직 동일 (④번 참조)
정책: 일반티켓 = 즉시 사용 가능한 쿠폰/교환권, 예약티켓 = 날짜/시간 예약 필요 상품. 예약티켓은 예약 일정 관리 필요.
7 판매상태

15 판매사 조회 팝업

호출: ②번 필터 [조회] 버튼 클릭

  • 구조: 검색 입력 + [검색] → 코드/판매사명 라디오 목록 → [취소] [선택]
  • 검색: 판매사명 기준 부분 일치 (LIKE)
  • [선택]: 라디오 선택된 판매사명을 필터 입력 필드에 반영
  • [취소]: 팝업 닫기 (값 변경 없음)
  • 선택 완료 후 하위업체 드롭박스 목록 갱신 및 활성화
정책: 활성(active) 상태인 판매사만 팝업 목록에 노출. 비활성 판매사는 조회 불가.
