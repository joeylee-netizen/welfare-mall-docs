Route: /bo/products/ticket/form

진입 흐름

  • 티켓상품 목록(BO-PDM-041) → [등록] 버튼 → 신규 등록
  • 티켓상품 승인목록(BO-PDM-043) → 상품명 클릭 → 수정
  • 목록 → 등록/수정(폼) → 저장 플로우

관련 문서: BO-PDM-021, 030, 031, 032, 033, 034

기본정보 탭 — 편집 가능 폼 (4개 영역)

1.1 기본정보

  1. 외부연동 여부 — readonly. 시스템 자동 설정값
  2. 상품명 * — input text (full width). 최대 100 bytes (한글 50자)
  3. 상품코드 — readonly. 승인완료 시 자동 부여(13자리)
  4. 판매사 상품코드 — input number (선택)
  5. 다국어 상품명 — input text. 최대 100 bytes (선택)
  6. 판매사 * — readonly input + [조회] 팝업
  7. 하위업체 — select. 판매사 선택 후 활성화
  8. 상품키워드 — input + [등록하기] → 태그(chip). 최대 10개

1.1-A 티켓정보 (티켓 전용)

  1. 상품유형 * — radio (일반티켓/예약티켓). 승인완료 후 수정불가
  2. 티켓 타입 * — radio (모바일티켓/바우처). 승인완료 후 수정불가
  3. 유효기간 * — checkbox + date-range. 승인완료 후 수정불가
  4. 패스 타입 — select. 승인완료 후 수정불가
  5. 취소 가능일 — number (일). 승인완료 후 수정불가
  6. 이용필수규칙 — textarea. 승인완료 후 수정불가

1.2 추가정보

  1. 상품리뷰/Q&A/선물하기 — radio (가능/불가능)
  2. 최소/최대/특가 구매수량 — radio + number input

1.3 고객사 정보

  1. 노출 제외 고객사 — radio (미등록/등록) + 팝업 선택

1.4 판매상태

  1. 판매상태 변경 — select (판매중/판매일시중지/판매종료)

• 047(상세)과 차이: 등록정보 영역(승인상태/등록자/수정자 등) 제거

전시정보 탭 — 편집 가능 폼 (6필드)

  1. 전시여부 * — radio (전시/비전시)
  2. 노출채널 * — checkbox (전체/PC/모바일)
  3. 전시기간 * — date-range
  4. 담당MD * — readonly input + [조회] 팝업
  5. 표준카테고리 * — 3단 select + [등록]
  6. 전시카테고리 * — 테이블 (대표/경로/삭제)

판매정보 탭 — 편집 가능 폼 (5개 영역)

  1. 판매기간 * — checkbox "제한없음" + date-range
  2. 과세구분 * — radio (과세/면세/영세)
  3. 성인인증상품 * — radio (Yes/No)
  4. 판매가(VAT포함) * — input number
  5. 상품 마진율 — checkbox + input (%)
  6. 할인/쿠폰/적립금 프로모션 — readonly 테이블

옵션/재고 탭 — 편집 가능 폼

  1. 상품옵션 * — radio (사용안함/단일/복수)
  2. "사용안함": 재고수량 직접 입력
  3. "단일/복수": [옵션 등록] 팝업 + 옵션 목록 테이블

발급정보 탭 — 편집 가능 폼 (2개 영역)

  1. 발급방법 — readonly. 티켓타입 연동
  2. 배송비 정책 — readonly. "무료" 고정
  3. 교환/반품 기간 * — textarea (500자/1,000 bytes)
  4. 교환/반품 안내 * — textarea (500자/1,000 bytes)
  5. 교환/반품 불가 안내 * — textarea (500자/1,000 bytes)

상세정보 탭 — 편집 가능 폼 (3개 영역)

  1. 대표 이미지: 최대 5개
  2. 동영상: mp4 최대 1개
  3. 상품상세설명: PC/모바일 편집기

상품정보제공고시 탭 — 편집 가능 폼

  1. 입력방식 * — radio (연동/직접입력)
  2. 상품분류 * — select
  3. 편집 테이블 — 번호/항목/내용/+/-

하단 공통

  • 취소: 이전 화면(진입점)으로 이동
  • 미리보기: placeholder 모달
  • 저장: 저장 확인 모달 (primary)

047(상세)과의 차이

  • 등록정보 영역 제거 (승인상태/등록자/수정자 등)
  • 샘플 데이터 비움 (신규 등록 기준 빈 폼)
  • 판매상태 섹션은 수정 모드 대응으로 유지
