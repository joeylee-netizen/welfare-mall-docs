BO-PDM-045 — 티켓상품 등록수정 화면

메뉴 경로: 상품 관리 > 상품 등록/승인 관리 > 티켓상품 등록/수정

Route: /bo/products/ticket/form

관련 문서

  • 컴포넌트: BO-PDM-021 (티켓상품 등록/수정 폼)
  • 액션: BO-PDM-030 (상품 등록)
  • 액션: BO-PDM-031 (상품 수정)
  • 액션: BO-PDM-032 (상품 삭제)
  • 액션: BO-PDM-033 (상품 승인요청)
  • 액션: BO-PDM-034 (상품 승인철회)

탭 모드 전환

  • 등록: 신규 상품 등록 폼
  • 수정(REGISTERING): 미승인 상품 수정
  • 수정(APPROVED): 승인된 상품 수정
  • 조회(PENDING): 승인대기 중 조회전용

섹션 구성

  • 기본정보: 상품코드, 요청코드, 상품유형, 판매사, 상품명
  • 티켓 정보: 티켓유형, 유효기간, 사용처, 사용가능요일, 이용안내, 예약안내
  • 상태정보: 승인상태(badge), 판매상태, 판매기간
  • 승인 이력: 수정/조회 모드만 표시

모드별 하단 버튼

  • 등록: 목록 / 임시저장 / 저장 / 승인요청
  • 수정(REG): 목록 / 저장 / 삭제 / 승인요청
  • 수정(APR): 목록 / 저장 / 판매일시중지 / 판매종료
  • 조회(PND): 목록 / 승인철회
