# 티켓상품 승인목록 화면

## 수정 이력

| 버전 | 날짜 | 작성자 | 변경 내용 |
|------|------|--------|----------|
| v1.0 | 2026-04-13 | 기획자 | 초안 작성 |

## 화면 개요

티켓상품(쿠폰형/예약형)의 승인 요청 목록을 조회하고, 개별/일괄 승인 및 반려 처리를 수행하는 화면이다. 기본 필터가 "승인대기"(PENDING)로 설정되어 처리 대기 항목을 우선 표시한다.

## 레이아웃

- **GNB**: 다크 헤더(#1a1a2e) — 로고, BO 관리자, 사용자 정보
- **LNB**: 확장형 사이드바 — 상품 관리 그룹 확장, "티켓상품 승인 목록" 활성
- **Content**: 검색 필터 → 툴바 → 테이블 → 페이지네이션
- **모달**: 승인 확인 모달, 반려 사유 모달

## 구성 요소

### 검색/필터 영역

- 컴포넌트 참조: [BO-PDM-023](../03-components/BO-PDM-023_티켓상품-승인-목록-테이블.md)
- 필터 항목:
  - 승인상태: 기본값 "승인대기"(PENDING) — 전체 / 승인대기 / 등록중 / 승인철회 / 승인완료 / 반려
  - 상품유형: 전체 / 쿠폰형 / 예약형
  - 상품명: 키워드 검색
  - 요청기간: 시작일 ~ 종료일

### 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 체크박스 | 일괄 처리용 선택 |
| No | 행 번호 |
| 요청코드 | REQ-YYYY-NNNN |
| 상품명 | 상품명 **링크** — 클릭 시 티켓상품 등록수정 화면([BO-PDM-045](./BO-PDM-045_티켓상품-등록수정-화면.md)) 새 탭 열기 |
| 상품유형 | 쿠폰형 / 예약형 |
| 판매사 | 판매사명 |
| 승인상태 | Badge (REGISTERING, PENDING, WITHDRAWN, APPROVED, REJECTED) |
| 요청일 | YYYY-MM-DD |
| 요청자 | 요청자명 |
| 관리 | PENDING: 승인/반려 버튼, 기타: 처리완료/철회됨 텍스트 |

### 상단 툴바

- 검색결과 N건 표시
- 일괄 승인 버튼: 체크된 PENDING 항목 일괄 승인

### 승인 확인 모달

- 안내 문구: "선택한 상품을 승인하시겠습니까?"
- 승인 후 판매 가능 상태 전환 안내
- 취소 / 승인 버튼
- 액션: [BO-PDM-035](../04-actions/BO-PDM-035_상품-승인.md), [BO-PDM-036](../04-actions/BO-PDM-036_상품-일괄승인.md)

### 반려 사유 모달

- 상품 정보 표시 (요청코드, 상품명)
- 반려 사유 Textarea (필수)
- 취소 / 반려 버튼
- 액션: [BO-PDM-037](../04-actions/BO-PDM-037_상품-반려.md)

## 기능 명세

- 액션 참조: [BO-PDM-039](../04-actions/BO-PDM-039_상품-승인목록-조회.md) (상품 승인목록 조회)
- 페이지 로드 시 승인대기 목록 자동 조회
- 전체 선택 체크박스: 현재 페이지 전체 행 선택/해제
- 개별 승인: 해당 행의 승인 버튼 → 승인 확인 모달
- 개별 반려: 해당 행의 반려 버튼 → 반려 사유 모달
- 일괄 승인: 체크된 항목 → 승인 확인 모달

## 상태 처리

| 상태 | 설명 | UI 표현 |
|------|------|---------|
| 로딩 | API 호출 중 | 테이블 영역에 로딩 스피너(skeleton) 표시, 검색/승인/반려 버튼 비활성화 |
| 데이터 없음 | 조회 결과 0건 | "조회 결과가 없습니다." 메시지 + [필터 초기화] 버튼 |
| 오류 (400) | 요청 파라미터 오류 | 토스트: "입력 조건을 확인해 주세요." |
| 오류 (409) | 상태 충돌 | 토스트: "상품 상태가 변경되었습니다. 목록을 갱신합니다." + 자동 재조회 |
| 오류 (500) | 서버 오류 | 토스트: "서버 오류가 발생했습니다. 잠시 후 다시 시도해 주세요." + [재시도] 버튼 |
| 네트워크 오류 | 연결 실패 | 토스트: "네트워크 연결을 확인해 주세요." |

### 승인/반려 후 목록 갱신

- 승인/반려 성공 후: **현재 페이지 재조회** (필터 조건 유지)
- 체크박스 선택 상태 초기화
- 검색결과 건수 갱신
