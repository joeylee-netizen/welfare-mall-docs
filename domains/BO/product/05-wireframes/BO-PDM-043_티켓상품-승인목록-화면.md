# 티켓상품 승인목록 화면

| 버전 | 날짜 | 작성자 | 변경 내용 |

| v2.0 | 2026-04-17 | 기획자 | 전면 재설계 — 042 기준 구조 적용, 필터 13개, 테이블 24컬럼, 팝업/모달 6개, 디스크립션 패널 추가. 브랜드/모델명 제거, 상품유형 일반티켓/예약티켓 변경 |

## 화면 개요

티켓상품의 등록/승인 요청 목록을 조회하고, 개별/일괄 승인 및 반려 처리를 수행하는 화면이다. [BO-PDM-041](./BO-PDM-041_티켓상품-목록-화면.md) 티켓상품 목록 화면을 베이스로 하되, 승인 관리에 특화된 필터(요청구분, 임시저장 여부, 승인상태)와 테이블 컬럼(승인상태, 승인요청일, 승인/반려 버튼)을 추가 구성한다.

## 레이아웃

- **GNB**: 다크 헤더(#1a1a2e) — 로고, BO 관리자, 사용자 정보
- **LNB**: 확장형 사이드바 — 상품 관리 그룹 확장, "티켓상품 승인 목록" 활성
- **Content**: 검색 필터(테이블형 2열) → 조회 버튼 → 상단 툴바 → 테이블(가로·세로 스크롤) → 페이지네이션
- **모달/얼럿**: 승인 확인 얼럿, 반려 사유 입력 팝업, 조회 팝업(판매사/MD)

## 기능 명세

### 기본 동작

- 기본 정렬: 상품요청코드 기준 내림차순
- 페이지 로드 시 자동 조회
- 액션 참조: [BO-PDM-039](../04-actions/BO-PDM-039_상품-승인목록-조회.md) (상품 승인목록 조회)

### 검색어 모드 전환

- 검색어 드롭박스에서 "사용안함" 외 항목(상품명/상품요청코드/키워드) 선택 시:
  - 1~12번 필터 전체 비활성화 (disabled)
  - 검색어 텍스트 입력 필드만 활성 상태
- "사용안함" 재선택 시: 모든 필터 활성화 복원

### 체크박스 "전체" 토글

- "전체" 체크 시: 나머지 개별 항목 모두 해제
- 개별 항목 체크 시: "전체" 자동 해제
- 모든 개별 항목 해제 시: "전체" 자동 체크

### 조회 팝업 (판매사, MD)

- 공통 구조: 검색 입력 + 검색 버튼 → 코드/이름 라디오 목록 → 취소/선택 버튼
- 선택 시 해당 필터 입력 필드에 값 반영
- 판매사 팝업: 선택 완료 후 하위업체 드롭박스 활성화

### 기간 퀵선택

- 기간유형: 상품등록일(기본) / 최종수정일 / 승인요청일
- 퀵선택 라디오: 오늘 / 최근 7일(기본) / 최근 1개월 / 최근 3개월 / 최근 1년
- 라디오 선택 시 시작일·종료일 자동 계산

### 링크 동작

- 상품요청코드 / 상품명 클릭 → [BO-PDM-045](./BO-PDM-045_티켓상품-등록수정-화면.md) **브라우저 새 탭** 열기 (기본정보 탭으로 이동, 탭별 순차 호출)
- 판매사 클릭 → 판매사 정보 팝업 호출

### 버튼 활성화/비활성화 규칙

| 승인상태 | [승인] 버튼 | [반려] 버튼 | 체크박스 |
|---------|:---------:|:---------:|:------:|
| 상품등록중 | 비활성화 | 비활성화 | 활성화 |
| 승인대기 | **활성화** | **활성화** | 활성화 |
| 승인철회 | 비활성화 | 비활성화 | 활성화 |
| 승인반려 | 비활성화 | 비활성화 | 활성화 |
| 승인완료 | 비활성화 | 비활성화 | 활성화 |

### 승인 처리

- 개별/일괄 **[승인]** → 얼럿: "선택한 상품을 승인 하시겠습니까?" (확인/취소)
  - 확인 → 승인 처리 → "선택한 상품이 승인완료 되었습니다." (확인)
  - 이미 승인완료 포함 시: "이미 승인완료된 상품이 있습니다." (확인)
  - API: PATCH `/api/v1/products/{product_id}/approve` — [BO-PDM-035](../04-actions/BO-PDM-035_상품-승인.md)

### 반려 처리

- 개별/일괄 **[승인반려]** → 얼럿: "반려된 상품은 승인요청이 있기 전까지 재승인할 수 없습니다. 선택한 상품을 반려 처리 하시겠습니까?" (확인/취소)
  - 확인 → **반려사유 입력 팝업** 호출
  - 이미 반려 포함 시: "이미 반려된 상품이 있습니다." (확인)
  - API: PATCH `/api/v1/products/{product_id}/reject` — [BO-PDM-037](../04-actions/BO-PDM-037_상품-반려.md)
