BO-PDM-044 — 배송상품 등록수정 화면

메뉴 경로: 상품 관리 > 상품 등록/승인 관리 > 배송상품 등록/수정

Route: /bo/products/delivery/form

기본정보 탭 — 5개 영역

1.1 기본정보 등록

  1. 상품명 * — input (full width). 필수, 최대 200자
  2. 상품코드 — readonly. 13자리 자동
  3. 요청코드 — readonly
  4. 판매사 * — readonly + [조회] 팝업. 하위업체 연동
  5. 브랜드 * — readonly + [조회] 팝업
  6. 상품키워드 — input + [등록하기]. 태그 형태. 최대 10개

1.2 추가정보

제조자, 원산지, 리뷰/Q&A/선물 라디오, 구매수량 3종(사용안함/사용 토글)

1.3 고객사 정보

미등록/등록 라디오. "등록" 시 고객사 조회 팝업 활성

1.4 판매상태

판매상태 변경 select (판매중/판매일시중지/판매종료)

1.5 승인 이력

테이블(No, 요청일, 처리일, 처리자, 상태, 비고)

전시정보 탭 — 6필드

  1. 전시여부 * — 전시/비전시
  2. 노출채널 * — 전체/PC/모바일 체크박스
  3. 전시기간 * — date-range
  4. 담당MD * — 팝업 선택 "MDID(MD명)"
  5. 표준카테고리 * — 3단 select + [등록]
  6. 전시카테고리 * — 테이블(대표 라디오/경로/삭제)

판매정보 탭 — 5개 영역

  1. 3.1 판매정보: 판매기간(제한없음+date), 과세구분, 성인인증
  2. 3.2 가격정보: 판매가, 마진율/마진, 계약마진율/마진
  3. 3.3 할인 프로모션: 등록/수정REG=안내문구, 수정APR/조회=readonly 테이블
  4. 3.4 쿠폰 프로모션: 동일
  5. 3.5 적립금 프로모션: 동일

옵션/재고 탭

  1. 상품옵션 * — 사용안함/단일/복수
  2. 사용안함: 재고수량 직접 입력
  3. 단일/복수: [옵션 등록] 팝업 + 옵션목록 테이블

배송정보 탭 — 3개 영역

  1. 5.1 출고지: select + readonly 9필드 연동
  2. 5.2 반품: select + readonly 9필드 연동
  3. 5.3 교환: select + readonly 10필드 연동

상세정보 탭 — 3개 영역

  1. 6.1 대표 이미지: 최대 5개, 대표 라디오, 미리보기
  2. 6.2 동영상: mp4 1개, 동영상>이미지 노출순서
  3. 6.3 상세설명: 전체/PC 라디오, PC/모바일 에디터

상품정보제공고시 탭

  1. 입력방식 * — 연동/직접입력
  2. 상품분류 * — 표준카테고리 기준
  3. 편집 테이블 — 번호/항목/내용 + 추가/삭제
  4. 기본 10행 노출, 스크롤 시 5건 추가(lazy-load)
