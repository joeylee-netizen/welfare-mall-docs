## 화면 개요

BO 관리자가 할인프로모션을 검색·조회·관리하는 목록 화면이다. [BO-PDM-002](../01-policies/BO-PDM-002_할인프로모션-정책.md)의 할인프로모션 정책에 따라 프로모션 3종(MZ_VENDOR/MZ_PLATFORM/VENDOR)과 4개 상태(DRAFT/ACTIVE/PAUSED/ENDED)를 조회한다.

- **정책:** [BO-PDM-002](../01-policies/BO-PDM-002_할인프로모션-정책.md)
- **컴포넌트:** [BO-PDM-026](../03-components/BO-PDM-026_할인프로모션-목록-테이블.md)
- **조회 액션:** [BO-PDM-03F](../04-actions/BO-PDM-03F_할인프로모션-목록-조회.md)
- **중지·삭제 액션:** [BO-PDM-03E](../04-actions/BO-PDM-03E_할인프로모션-중지-삭제.md)

## 구성 요소

### 검색 필터 (6개)

| No | 필터명 | 입력 유형 | 비고 |
|----|--------|-----------|------|
| 1 | 프로모션구분 | 체크박스 | 전체/메가존(판매사부담)/메가존(복지몰부담)/판매사 |
| 2 | 판매사 | 조회 팝업 | 팝업 선택 → 판매사명 출력 |
| 3 | 진행상태 | 체크박스 | 전체/임시저장/진행중/중지/종료 |
| 4 | 쿠폰적용여부 | 체크박스 | 전체/적용 가능/적용 불가 |
| 5 | 기간 | Select + DateRange + Radio | 등록일/프로모션 시작일/프로모션 종료일 + 퀵선택 |
| 6 | 검색어 | Select + Text | 프로모션명/프로모션코드/상품코드 |

### 상단 툴바

- 좌측: 검색결과 N건, 출력건수 셀렉트 (20/50/100)
- 우측: `등록`, `중지`, `삭제` 버튼

### 목록 테이블 (13컬럼)

[BO-PDM-026](../03-components/BO-PDM-026_할인프로모션-목록-테이블.md) 컬럼 구성 참조.
체크박스, No, 프로모션ID, 프로모션명, 할인구분, 판매사코드, 판매사, 쿠폰적용여부, 프로모션기간, 진행상태, 등록자, 등록일, 조회 버튼

### 페이지네이션

- 하단 중앙 배치
- 이전/다음 버튼 + 페이지 번호

## 기능 명세

### 검색/초기화

- `검색` 버튼 또는 Enter 키로 조회 실행
- `초기화` 버튼으로 필터 기본값 복원 (자동 재검색 없음)

### 체크박스 선택

- 헤더 체크박스: 현재 페이지 전체 선택/해제
- 행 체크박스: 개별 프로모션 선택

### 등록 버튼

- 클릭 시 할인프로모션 등록 화면([BO-PDM-049](./BO-PDM-049_할인프로모션-등록-화면.md))으로 이동 (등록 모드)

### 중지 버튼

- ACTIVE 상태 프로모션만 대상
- 확인 모달 표시 후 일괄 중지 처리 (ACTIVE → PAUSED)

### 삭제 버튼

- DRAFT/PAUSED/ENDED 상태 프로모션만 대상
- 확인 모달 표시 후 일괄 삭제 처리 (→ DELETED, soft delete)

### 조회 버튼

- 테이블 행의 `조회` 버튼 클릭 시 할인프로모션 등록 화면([BO-PDM-049](./BO-PDM-049_할인프로모션-등록-화면.md))으로 이동 (수정 모드)
- URL 파라미터로 `promotion_id` 전달
