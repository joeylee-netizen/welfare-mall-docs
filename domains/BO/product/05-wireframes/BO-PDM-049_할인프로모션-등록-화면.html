화면 기획 설명

BO-PDM-049 v2.0 — 할인프로모션 등록 화면

1 기본정보 카드
  • 프로모션명: 필수, 최대 100자
  • 프로모션구분: 라디오 3종 — 메가존(판매사부담) / 메가존(복지몰부담) / 판매사할인
  • 판매사: 조회 팝업으로 선택, 할인 비용 부담 판매사
  • 할인금액: 원 단위, 0 초과 정수
  • 수정 모드 시 프로모션코드(readonly) 표시
정책: 프로모션 3종 — MZ_VENDOR(판매사100%부담), MZ_PLATFORM(복지몰100%부담), VENDOR(판매사자체) (BO-PDM-002 §1)
2 프로모션 조건 카드
  • 프로모션기간: 시작일시 ~ 종료일시 (datetime-local)
  • 쿠폰적용여부: 토글 스위치, 기본값 "적용 가능"
  • 비고: 선택 입력 (관리자 메모)
정책: 동일 상품에 기간이 중복되는 프로모션은 등록 불가 (BO-PDM-002)
3 대상상품 카드
  • "상품 추가" 클릭 → 상품 검색 팝업
  • 승인완료(APPROVED) 상품만 검색/선택 가능
  • 복수 상품 체크박스 선택
  • X 버튼으로 개별 상품 제거
  • 최소 1건 이상 필수
정책: 승인완료 상품만 프로모션 등록 가능 (BO-PDM-002)
하단 버튼
  • 취소: 목록 화면(BO-PDM-048)으로 이동, 변경사항 있으면 확인 모달
  • 저장: 클라이언트 검증 → 확인 모달 → API 호출 → 목록으로 이동
등록 플로우
  • 1. 프론트엔드 필수값 검증
  • 2. 저장 확인 모달 표시
  • 3. 백엔드: 승인완료 상품 체크
  • 4. 백엔드: 기간 중복 체크
  • 5. 프로모션코드 자동 발급
  • 6. DB 저장 (status: ACTIVE)
