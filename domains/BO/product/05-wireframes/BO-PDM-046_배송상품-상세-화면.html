BO-PDM-046 — 배송상품 상세 화면

메뉴 경로: 상품 관리 > 배송상품 관리 > 배송상품 목록 > 상품 상세

Route: /bo/products/delivery/:id

진입 흐름

  • 배송상품 목록(BO-PDM-040)에서 상품명 클릭
  • 승인완료(APPROVED) 상품 대상
  • 목록 → 상세(편집) → 저장 플로우

기본정보 탭 — 편집 가능 폼 (5개 영역)

1.1 기본정보

  1. 상품명 * — input text (full width)
    • 검증: 필수. 최대 200자. 특수문자 허용
  2. 상품코드 — readonly. 승인완료 시 자동 부여(13자리)
  3. 판매사 상품코드 — input text. 판매사 자체 관리 코드(선택)
  4. 다국어 상품명 — input text (full width). 영문/다국어(선택)
  5. 판매사 — readonly input + [조회] 팝업
    • 팝업 선택 시 하위업체 select 자동 갱신
    • 정책: 승인완료 후 판매사 변경 불가
  6. 하위업체 — select. 판매사 선택 후 활성화. 해당 판매사의 하위업체 목록
  7. 브랜드 — readonly input + [조회] 팝업
    • 정책: 배송형 상품은 브랜드 등록 필수(BO-PDM-001)
  8. 모델명 — input text. 제품 모델 식별 코드
  9. 상품키워드 — input + [등록하기] → 태그(chip) 출력
    • 등록 시 하단에 태그 추가, × 클릭 삭제
    • 정책: 최대 10개. FO 검색 키워드로 활용

1.2 추가정보

  1. 제조자 — input text
  2. 원산지 — input text
  3. 상품리뷰 등록 — radio (가능/불가능). 기본값: 가능
  4. Q&A 등록 — radio (가능/불가능). 기본값: 가능
  5. 선물하기 — radio (가능/불가능). 기본값: 가능
    • 정책: 설치 상품은 선물하기 불가능 고정
  6. 최소 구매수량 — radio(사용안함/사용) + number input
    • "사용안함" 선택 시 숫자 입력 disabled (제한 없음)
    • 정책: 1 이상 정수. "1회당 구매 가능한 최소 수량"
  7. 최대 구매수량 — radio(사용안함/사용) + number input
    • 정책: 최소 구매수량 이상이어야 함. "1회당 구매 가능한 최대 수량"
  8. 특가 구매수량 — radio(사용안함/사용) + number input
    • 정책: "판매기간 동안 1인당 구매 가능한 총 수량". 누적 집계

1.3 고객사 정보

  1. 노출 제외 고객사 — radio (미등록/등록). 기본값: 미등록
    • "미등록": 하위 입력 영역 전체 비활성(opacity 0.4, pointer-events:none)
    • "등록": 하위 입력 활성화
  2. 고객사 입력 — readonly input + [조회] + [등록]
    • 정책: 등록된 고객사 소속 임직원에게 해당 상품 FO 비노출
  3. 등록 목록 — 태그(chip) 형태. × 클릭 삭제

1.4 등록정보 (readonly)

  1. 승인상태 — Badge 표시(승인완료/반려 등). 상태별 색상 구분
  2. 반려사유 — 반려 시에만 값 표시, 정상이면 "-"
  3. 등록자 / 등록일시 — 최초 등록 정보
  4. 승인자 / 승인일시 — 최종 승인 정보
  5. 수정자 / 수정일시 — 마지막 수정 정보

1.5 판매상태

  1. 판매상태 변경 — select (판매중/판매일시중지/판매종료)
    • 전환 규칙: 판매중→일시중지/종료, 일시중지→판매중 (BO-PDM-001 정책)
    • 정책: 판매종료 선택 시 confirm("판매종료 시 FO에서 비노출됩니다")
    • 일시품절/품절은 재고 연동 자동 전환(수동 선택 불가)

1.6 승인 이력

• 표시 위치: 기본정보 탭에서만 표시
• 테이블 열: No | 요청일 | 처리일 | 처리자 | 처리상태(Badge) | 비고
• 정렬: 최신순(요청일 desc)
• 정책: 반려 시 비고에 반려사유 표시. 승인 시 "-"

판매사 조회(vendorPopup046), 브랜드 조회(brandPopup046), 고객사 조회(clientPopup046)

전시정보 탭 — 편집 가능 폼 (6필드)

2.1 전시정보

  1. 전시여부 * — radio (전시 / 비전시)
    • 기본값: 전시
    • 전시: 전시기간 해당 시 FO 노출
    • 비전시: FO 비노출 (판매상태와 무관)
    • 정책: 비전시 선택 시 전시기간/노출채널은 유지되나 FO 미반영
  2. 노출채널 * — checkbox (전체 / PC / 모바일)
    • "전체" 체크 시 PC+모바일 자동 체크 + disabled
    • "전체" 해제 시 PC/모바일 개별 선택 가능
    • 정책: 최소 1개 채널 선택 필수. 미선택 시 저장 불가
  3. 전시기간 * — date-range (시작일 ~ 종료일)
    • 네이티브 date input. 시작일 ≤ 종료일 필수
    • 정책: 판매기간(탭3) "기간 직접 설정" 시 전시기간이 판매기간 초과 불가
    • 초과 시 alert("전시기간은 판매기간을 초과할 수 없습니다")
  4. 담당MD * — readonly input + [조회] 팝업
    • 팝업 선택 → "MDID(MD명)" 형태 출력 (예: MD001(김담당))
    • 정책: 담당MD 변경 시 표준카테고리 대분류 목록 갱신 (해당 MD 관리 대분류만 호출)
  5. 표준카테고리 * — 3단 select (대/중/소분류) + [등록]
    • 대분류: 담당MD 선택 후 해당 MD 관리 카테고리만 호출
    • 중분류: 대분류 선택 시 연동 갱신
    • 소분류: 중분류 선택 시 연동 갱신
    • [등록] 클릭 시 3단 선택값을 전시카테고리 테이블에 행 추가
    • 검증: 3단 모두 선택해야 등록 가능
  6. 전시카테고리 * — 테이블 (대표 라디오 / 경로 / 삭제)
    • 대표: 라디오 단일 선택. 첫 행 default. FO 메인 카테고리 경로로 노출
    • 삭제: 행 제거. 최소 1행 필수
    • 정책: 대표 카테고리 삭제 시 다음 행이 자동 대표 승계

팝업 1개

담당MD 조회(mdPopup046) — MD코드/MD명 라디오 목록. 샘플: MD001 김담당, MD002 이담당, MD003 박담당

판매정보 탭 — 편집 가능 폼 (5개 영역)

3.1 판매정보 등록

  1. 판매기간 * — checkbox "제한없음" + date-range(시작~종료)
    • 기본값: "제한없음" 체크(ON)
    • 체크 시: 시작일/종료일 input disabled, 판매기간 제한 없음으로 적용
    • 체크 해제 시: date input 활성화, 시작일/종료일 직접 입력
    • 정책: 기간 설정 시 전시기간(탭2) 범위를 초과할 수 없음 → 초과 시 alert("판매기간은 전시기간을 초과할 수 없습니다")
    • 검증: 시작일 ≤ 종료일 필수. 시작일은 오늘 이후만 가능(수정 시 기존값 유지 허용)
  2. 과세구분 * — radio 3종(과세 / 면세 / 영세)
    • 기본값: 과세
    • 정책: 면세 선택 시 판매가=공급가(VAT 0). 영세 선택 시 수출 상품 대상, 영세율 적용
    • 승인완료 후 변경 시 가격정보 재계산 필요
  3. 성인인증상품 * — radio (Yes / No)
    • 기본값: No
    • 정책: Yes 선택 시 FO 구매 시 성인인증 절차 필수 적용. 주류·담배 등 법적 성인 제한 상품 대상

3.2 가격정보

  1. 판매가(VAT포함) * — input number
    • 숫자만 입력 가능. 1,000단위 콤마 자동 포맷
    • 검증: 0 초과 필수. 최대 99,999,999원
    • 정책: 과세 상품은 VAT 포함 금액 입력. 면세 상품은 공급가=판매가
  2. 상품 마진율 — checkbox + input number (%)
    • 기본값: 체크 해제(비활성)
    • 체크 시: % 입력 활성화
    • 정책: 계약 마진율(PO 계약값) 초과 입력 불가 → 초과 시 alert("계약 마진율(12%)을 초과할 수 없습니다")
    • 계산: 상품마진 = 판매가 × 상품마진율
  3. 상품 마진 — readonly (자동계산)
    • = 판매가 × 상품마진율. 마진율 미설정 시 "-" 표시
  4. 계약 마진율 — readonly (PO 계약값)
    • 판매사 계약 시 설정된 마진율. 수정 불가

    • 정책: 분류 변경 시 기존 고시 항목 초기화 → confirm("상품분류를 변경하면 기존 고시 항목이 초기화됩니다. 변경하시겠습니까?")
    • 변경 확인 시 새 분류의 표준 항목으로 교체
    • 직접입력 모드에서는 분류 변경 시 테이블 영향 없음

    • 열 구성: 번호(input) | 항목(input) | 내용(input) | +/- 버튼
    • 번호: 자동 순번. 수동 변경 시 정렬 순서 반영
    • 항목: 고시 항목명. 연동 시 기본값 자동 입력, 수정 가능
    • 내용: 고시 내용. 직접 입력 필수
    • [+] 버튼: 해당 행 아래에 새 빈 행 추가
    • [-] 버튼: 해당 행 삭제. 마지막 1행은 삭제 불가
    • 검증: 항목명·내용 모두 빈 값이면 저장 시 해당 행 제외(경고 없음)

    • 스크롤: 기본 10행 노출. 스크롤 시 5건씩 추가 표시(lazy-load). 테이블 영역 max-height: 500px
    • 안내: 하단 "스크롤하여 더 보기 (노출 수 / 전체 수)" 표시. 전체 노출 완료 시 자동 숨김
