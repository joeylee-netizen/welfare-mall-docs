Route: /bo/products/ticket/approval

1 카테고리
  • (a)표준카테고리 / (b)전시카테고리 택1
  • 1차 → 2차 → 3차 순차 선택
  • 1차 옵션: 숙박/여행/문화/레저/외식/뷰티/교육
  • Default: 전체. 상위 선택 시 하위 '전체' 노출

2 판매사
  • 조회 팝업으로 판매사 선택 → 필드에 판매사명 출력
  • 하위업체: Default 비활성, 판매사 선택 시 활성화
  • 최근등록순 내림차순, 5개 이상 시 스크롤
3 MD
  • 조회 팝업으로 MD 담당자 검색·선택

  • 기간유형: 상품등록일(기본) / 최종수정일 / 승인요청일
  • 날짜 직접 선택 (최대 1년)
  • 퀵선택: 오늘 / 최근7일(기본) / 1개월 / 3개월 / 1년
041 대비 "승인요청일" 옵션 추가

  • [승인]: 체크된 상품 일괄 승인 (승인대기만 활성)
