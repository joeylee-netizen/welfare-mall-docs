## 화면 개요

티켓상품 목록([BO-PDM-041](./BO-PDM-041_티켓상품-목록-화면.md))에서 상품명 클릭 시 진입하는 **티켓상품 상세 화면**이다. 7개 탭 전체가 편집 가능한 폼으로 제공된다. 하단에 승인 이력과 저장/취소 버튼을 제공한다.

## 진입 조건

- 티켓상품 목록(BO-PDM-041)에서 **상품명 링크 클릭**
- 대상: 승인완료(APPROVED) 상태 상품
- 흐름: 목록(BO-PDM-041) → **상세(BO-PDM-047)** → 저장

## 레이아웃

- **GNB**: 다크 헤더(#1a1a2e) — 로고, BO 관리자, 사용자 정보
- **LNB**: 확장형 사이드바 — 상품 관리 그룹 확장, "티켓상품 목록" 활성
- **Content**: 7개 탭 → 탭 콘텐츠(카드 분리형) → 승인 이력 → 하단 버튼
- **영역 구분**: 각 `.form-section`이 카드(border + shadow + padding) 형태로 시각적 분리. 콘텐츠 영역 배경(`#f4f6f8`)과 카드 배경(`#fff`) 대비로 가독성 확보.
- **등록정보 차별화**: `.form-section--readonly` 클래스 — 읽기전용 영역은 `#f9fafb` 배경으로 편집 영역과 구분.

## 기능 명세

- 기본정보 탭: 편집 가능 폼 (6개 영역 — 기본정보, 티켓정보, 추가정보, 고객사, 등록정보, 판매상태)
- 전시정보 탭: 편집 가능 폼 (6개 필드)
- 판매정보 탭: 편집 가능 폼 (5개 영역 — 판매정보등록, 가격정보, 할인/쿠폰/적립금 프로모션)
- 옵션/재고 탭: 편집 가능 폼 (옵션 라디오 + 옵션등록 팝업 + 옵션목록 테이블)
- 발급정보 탭: 편집 가능 폼 (단일 영역 — 발급방법, 배송비 정책, 교환/반품 3종)
- 상세정보 탭: 편집 가능 폼 (3개 영역 — 이미지/동영상/상세설명)
- 상품정보제공고시 탭: 편집 가능 폼 (입력방식/상품분류/편집테이블)
- 탭 전환: JavaScript `switchTab(tabId)` 함수
- 키워드 등록: `addKeyword()` — 입력값을 태그(chip)로 추가
- 태그 삭제: `removeTag(el)` — 키워드/고객사 태그 공용 삭제
- 구매수량 토글: `toggleQtyField(name)` — 사용안함/사용 라디오에 따라 숫자 입력 활성/비활성
- 고객사 섹션 토글: `toggleClientSection()` — 미등록/등록 전환 시 입력 영역 활성/비활성
- 노출채널 전체 토글: `toggleChannelAll()` — "전체" 체크 시 PC/모바일 자동 체크+disabled
- 전시카테고리 등록: `addDisplayCategory()` — 표준카테고리 3단 select 값을 테이블에 행 추가
- 전시카테고리 삭제: `removeDisplayCategory(el)` — 행 제거
- 담당MD 선택: `selectMd047()` — 팝업에서 선택한 MD를 "MDID(MD명)" 형태로 출력
- 팝업 열기/닫기: `openPopup047(id)` / `closePopup047(id)`
- 고객사 등록: `addClient()` — 팝업 선택값을 태그로 추가
- 모달 열기/닫기: `openModal(id)` / `closeModal(id)`
- 판매기간 토글: `toggleSalePeriod()` — 제한없음 체크 시 date input disabled
- 상품마진율 토글: `toggleMarginRate()` — 체크박스로 마진율 입력 활성/비활성
- 옵션 사용 토글: `toggleOptionUse()` — 사용안함/단일/복수에 따라 영역 전환
- 상세정보 범위 토글: `toggleDetailScope()` — 전체/PC에 따라 모바일 편집기 활성/비활성
- 고시 입력방식 토글: `toggleNoticeMode()` — 연동/직접입력 전환
- 고시 행 추가/삭제: `addNoticeRow()` / `removeNoticeRow(el)`
- 상품유형 전환: `toggleTicketType()` — 일반티켓/예약티켓 UI 전환
