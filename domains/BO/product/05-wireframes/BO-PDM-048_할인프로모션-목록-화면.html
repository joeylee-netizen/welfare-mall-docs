화면 기획 설명

BO-PDM-048 v2.0 — 할인프로모션 목록 화면

1 프로모션구분
  • 체크박스: 전체 / 메가존(판매사부담) / 메가존(복지몰부담) / 판매사
  • 기본값: 전체
  • "전체" 선택 시 나머지 해제, 개별 선택 시 "전체" 해제
정책: 프로모션 3종 — MZ_VENDOR, MZ_PLATFORM, VENDOR (BO-PDM-002 §1)
2 판매사
  • 조회 버튼 클릭 → 판매사 검색 팝업
  • 팝업에서 선택 시 판매사명 표시
3 진행상태
  • 체크박스: 전체 / 임시저장 / 진행중 / 중지 / 종료
  • 기본값: 전체
  • "전체" 선택 시 나머지 해제, 개별 선택 시 "전체" 해제
정책: 4개 상태 — DRAFT/ACTIVE/PAUSED/ENDED (DELETED 제외) (BO-PDM-002 §8)
4 쿠폰적용여부
  • 체크박스: 전체 / 적용 가능 / 적용 불가
  • "전체" 선택 시 나머지 해제, 개별 선택 시 "전체" 해제
5 기간
  • 기간유형 드롭박스: 등록일 / 프로모션 시작일 / 프로모션 종료일
  • DatePicker: 시작일 ~ 종료일
  • 퀵선택 라디오: 오늘 / 7일 / 1개월(기본) / 3개월 / 1년
6 검색어
  • 프로모션명 / 프로모션코드 / 상품코드 택1 후 키워드 입력
  • 부분 일치(LIKE) 검색
상단 버튼
  • 등록: 할인프로모션 등록 화면(BO-PDM-049)으로 이동 (등록 모드)
  • 중지: 체크된 ACTIVE 프로모션 일괄 중지 (확인 모달)
  • 삭제: 체크된 DRAFT/PAUSED/ENDED 프로모션 일괄 삭제 (확인 모달)
정책: ACTIVE→PAUSED(중지), DRAFT/PAUSED/ENDED→DELETED(삭제) (BO-PDM-002 §8)
