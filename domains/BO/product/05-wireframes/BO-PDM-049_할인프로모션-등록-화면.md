# 할인프로모션 등록 화면

## 수정 이력

| 버전 | 날짜 | 내용 |
|------|------|------|
| v2.0 | 20260421 | 정책(BO-PDM-002) 기반 전면 재설계 — 판매사 선택 추가, 프로모션구분 3종 명확화, 수정 규칙 보강 |

## 화면 개요

BO 관리자가 할인프로모션을 등록·수정하는 폼 화면이다. [BO-PDM-002](../01-policies/BO-PDM-002_할인프로모션-정책.md)의 할인프로모션 정책에 따라 카드 분리형 단일 폼으로 3개 카드(기본정보, 프로모션 조건, 대상상품)로 구성된다.

- **정책:** [BO-PDM-002](../01-policies/BO-PDM-002_할인프로모션-정책.md)
- **컴포넌트:** [BO-PDM-027](../03-components/BO-PDM-027_할인프로모션-등록-폼.md)
- **등록 액션:** [BO-PDM-03C](../04-actions/BO-PDM-03C_할인프로모션-등록.md)
- **수정 액션:** [BO-PDM-03D](../04-actions/BO-PDM-03D_할인프로모션-수정.md)

---

## 진입 조건

| 진입 경로 | 모드 | URL |
|-----------|------|-----|
| 목록 화면 > `등록` 버튼 | 등록 모드 (빈 폼) | `/bo/promotions/form` |
| 목록 화면 > `조회` 버튼 클릭 | 수정 모드 (데이터 로드) | `/bo/promotions/form?id={promotion_id}` |

---

## 모드 제어

| 조건 | 모드 | 편집 범위 | 헤더 타이틀 |
|------|------|----------|------------|
| promotion_id 없음 | 등록 모드 | 모든 필드 입력 가능 | 할인프로모션 등록 |
| promotion_id 있음 + DRAFT | 수정 모드 | 전체 편집 가능 | 할인프로모션 수정 |
| promotion_id 있음 + ACTIVE | 수정 모드 | 종료일시, 쿠폰적용여부만 수정 | 할인프로모션 수정 |
| promotion_id 있음 + PAUSED/ENDED | 조회 모드 | 읽기전용 | 할인프로모션 상세 |

> 정책 BO-PDM-002 §9: DRAFT=전체수정, ACTIVE=종료일+쿠폰만, PAUSED/ENDED=수정불가

## 레이아웃

| Content | 카드 3개 + 하단 버튼 |

## 구성 요소

### 카드 1: 기본정보

| No | 필드명 | 입력 유형 | 필수 | 비고 |
|----|--------|-----------|------|------|
| 1 | 프로모션코드 | readonly | - | 수정 모드에서만 표시 |
| 2 | 프로모션명 | text | Y | 최대 100자 |
| 3 | 프로모션구분 | radio | Y | 메가존(판매사부담)/메가존(복지몰부담)/판매사 |
| 4 | 판매사 | 조회 팝업 | Y | 할인 비용 부담 판매사 선택 |
| 5 | 할인금액 | number | Y | 원 단위, 0 초과 |

### 카드 2: 프로모션 조건

| No | 필드명 | 입력 유형 | 필수 | 비고 |
|----|--------|-----------|------|------|
| 1 | 프로모션기간 | daterange | Y | 시작일시 ~ 종료일시 |
| 2 | 쿠폰적용여부 | toggle | Y | 가능/불가, 기본: 가능 |
| 3 | 비고 | textarea | N | 관리자 메모 |

### 카드 3: 대상상품

- `상품 추가` 버튼: 상품 검색 팝업 열기
- 서브테이블: 상품코드, 상품명, 상품유형, 판매가, 삭제(X)
- 승인완료(APPROVED) 상품만 검색·선택 가능

### 하단 버튼

| 모드 | 좌측 | 우측 |
|------|------|------|
| 등록 모드 | - | `취소`, `저장` (Primary) |
| 수정 (DRAFT) | - | `취소`, `저장` (Primary) |
| 수정 (ACTIVE) | - | `취소`, `저장` (Primary) |
| 조회 (PAUSED/ENDED) | - | `목록으로` |

## 상태 처리

| 상태 | UI 표현 |
|------|---------|
| 등록 초기 | 빈 폼, 모든 필드 편집 가능 |
| 수정 초기 | 데이터 로드, 상태별 편집 범위 적용 |
| 로딩 | 폼 비활성화, 버튼 로딩 상태 |
| 검증 실패 | 필드별 인라인 오류 메시지 |
| 기간 중복 오류 | 토스트: "동일 상품에 기간이 중복되는 프로모션이 존재합니다." |
| 미승인 상품 오류 | 토스트: "승인완료되지 않은 상품이 포함되어 있습니다." |
| 저장 성공 | 토스트 + 목록 화면 이동 |
