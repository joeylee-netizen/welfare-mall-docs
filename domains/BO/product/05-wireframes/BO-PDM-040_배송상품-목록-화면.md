# 배송상품 목록 화면

## 수정 이력

| 버전 | 날짜 | 작성자 | 변경 내용 |
|------|------|--------|----------|
| v1.0 | 2026-04-13 | 기획자 | 초안 작성 |

## 화면 개요

배송상품의 전체 목록을 조회·검색하는 화면이다. 판매상태별 필터링과 키워드 검색을 지원하며, 상품명 클릭 시 등록/수정 화면으로 이동한다.

## 레이아웃

- **GNB**: 다크 헤더(#1a1a2e) — 로고, BO 관리자, 사용자 정보
- **LNB**: 확장형 사이드바 — 상품 관리 그룹 확장, "배송상품 목록" 활성
- **Content**: 검색 필터 → 툴바 → 테이블 → 페이지네이션

## 구성 요소

### 검색/필터 영역

- 컴포넌트 참조: [BO-PDM-024](../03-components/BO-PDM-024_배송상품-목록-테이블.md)
- 필터 항목 (10개):
  - 카테고리 (최상단 배치): 표준카테고리 / 전시카테고리 셀렉트 선택 → 1차·2차·3차 depth 순차 셀렉트 (상위 선택 시 하위 활성화)
  - 상품코드: 직접 입력 (PRD-YYYY-NNNN)
  - 요청코드: 직접 입력 (REQ-YYYY-NNNN)
  - 상품유형: 전체 / 일반상품 / 옵션상품
  - 승인상태: 전체 / 등록중 / 승인대기 / 승인완료 / 반려 / 승인철회
  - 판매상태: 전체 / 판매중 / 판매일시중지 / 일시품절 / 품절 / 판매종료
  - 브랜드: 셀렉트 (전체 + 개별 브랜드)
  - 상품명: 키워드 검색 (LIKE)
  - 판매가: 최소 ~ 최대 범위 (원)
  - 등록기간: 시작일 ~ 종료일

### 목록 테이블

| 컬럼 | 설명 |
|------|------|
| No | 행 번호 |
| 상품코드 | PRD-YYYY-NNNN |
| 요청코드 | REQ-YYYY-NNNN |
| 상품명 | 링크 — 클릭 시 등록/수정 화면 이동 |
| 상품유형 | 일반상품 / 옵션상품 |
| 판매상태 | Badge 표시 (SELLING, SALES_PAUSED, TEMP_OUT_OF_STOCK, OUT_OF_STOCK, SALES_ENDED) |
| 브랜드 | 브랜드명 |
| 판매기간 | 시작일 ~ 종료일 |
| 등록일 | YYYY-MM-DD |

### 상단 툴바

- 검색결과 N건 표시
- 출력건수 선택: 20 / 50 / 100건

### 페이지네이션

- 하단 중앙 배치
- 이전/다음, 페이지 번호 버튼

## 기능 명세

- 액션 참조: [BO-PDM-038](../04-actions/BO-PDM-038_상품-목록-조회.md) (상품 목록 조회)
- 기본 정렬: 등록일 DESC
- 페이지 로드 시 자동 조회 (trigger: load)
- 검색 버튼 클릭 시 필터 조건으로 재조회
- 초기화 버튼 클릭 시 필터 초기화 후 재조회
