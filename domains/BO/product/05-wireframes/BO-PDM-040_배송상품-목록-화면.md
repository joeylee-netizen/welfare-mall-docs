# 배송상품 목록 화면

## 수정 이력

| 버전 | 날짜 | 작성자 | 변경 내용 |
|------|------|--------|----------|
| v2.1 | 2026-04-16 | 기획자 | 상품명 링크 대상을 상세 화면(BO-PDM-046)으로 변경 |

## 화면 개요

배송상품의 전체 목록을 조회·검색하는 화면이다. 12개 조회 필터(카테고리 연동, 조회 팝업, 체크박스 그룹, 기간 퀵선택 등)와 28컬럼 테이블로 구성되며, 검색어 모드 전환 시 단일 키워드 검색을 지원한다.

## 레이아웃

- **GNB**: 다크 헤더(#1a1a2e) — 로고, BO 관리자, 사용자 정보
- **LNB**: 확장형 사이드바 — 상품 관리 그룹 확장, "배송상품 목록" 활성
- **Content**: 검색 필터(테이블형 2열) → 툴바 → 테이블(가로 스크롤) → 페이지네이션

### 상단 툴바

- 검색결과 N건 표시
- 출력건수 선택: 20 / 50 / 100건

### 페이지네이션

- 하단 중앙 배치
- 이전/다음, 페이지 번호 버튼

## 기능 명세

- 액션 참조: [BO-PDM-038](../04-actions/BO-PDM-038_상품-목록-조회.md) (상품 목록 조회)
- 기본 정렬: 상품등록일 DESC
- 페이지 로드 시 자동 조회 (trigger: load)
- 검색 버튼 클릭 시 필터 조건으로 재조회
- 초기화 버튼 클릭 시 필터 초기화 후 재조회

### 검색어 모드 전환

- 검색어 드롭박스에서 "사용안함" 외 항목(상품명/상품코드/상품키) 선택 시:
  - 1~11번 필터 전체 비활성화 (disabled)
  - 검색어 텍스트 입력 필드만 활성 상태
- "사용안함" 재선택 시: 모든 필터 활성화 복원

### 조회 팝업 (판매사, MD, 브랜드)

- 공통 구조: 검색 입력 + 검색 버튼 → 코드/이름 라디오 목록 → 취소/선택 버튼
- 선택 시 해당 필터 입력 필드에 값 반영
- 판매사 팝업: 선택 완료 후 하위업체 드롭박스 활성화

### 기간 퀵선택

- 기간유형: 상품등록일(기본) / 최종수정일
- 퀵선택 라디오: 오늘 / 최근 7일(기본) / 최근 1개월 / 최근 3개월 / 최근 1년
- 라디오 선택 시 시작일·종료일 자동 계산

### 체크박스 "전체" 토글

- "전체" 체크 시: 나머지 개별 항목 모두 해제
- 개별 항목 체크 시: "전체" 자동 해제
- 모든 개별 항목 해제 시: "전체" 자동 체크
