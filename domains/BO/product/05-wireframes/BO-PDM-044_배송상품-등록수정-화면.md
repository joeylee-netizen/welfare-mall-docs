## 화면 개요

배송상품을 등록하거나 수정하는 폼 화면이다. **모드 전환 탭**(상단)과 **콘텐츠 탭**(7개)의 이중 탭 구조를 사용한다. 등록 모드에서는 탭별 순차 저장 후 승인요청이 활성화되며, 수정 모드에서는 모든 탭이 활성 상태이다.

**핵심 흐름**: 등록/수정(BO-PDM-044) → 승인요청 → BO 승인 → 상품코드 발급 → 상품 목록([BO-PDM-040](./BO-PDM-040_배송상품-목록-화면.md)) → 상세([BO-PDM-046](./BO-PDM-046_배송상품-상세-화면.md))

## 진입 조건

| 진입점 | 모드 | 설명 |
|--------|------|------|
| 배송상품 목록(BO-PDM-040) → [등록] 버튼 | register | 신규 상품 등록 |
| 배송상품 승인목록(BO-PDM-042) → 상품명 클릭 (REGISTERING) | editReg | 미승인 상태 상품 수정 |
| 배송상품 승인목록(BO-PDM-042) → 상품명 클릭 (APPROVED) | editApproved | 승인완료 상품 수정 |
| 배송상품 승인목록(BO-PDM-042) → 상품명 클릭 (PENDING) | viewPending | 승인대기 조회 전용 |

## 모드 정의 (4가지)

| 모드 | ID | 승인상태 | 설명 |
|------|----|----------|------|
| 등록 모드 | register | — | 신규 상품 등록. 상품코드 미표시, 요청코드 저장 후 표시. 탭 순차 저장 |
| 수정(REGISTERING) | editReg | 등록중 | 미승인 상품 수정. 삭제 가능. 모든 탭 활성 |
| 수정(APPROVED) | editApproved | 승인완료 | 승인완료 상품 수정. 판매상태 변경 가능. 미리보기 가능 |
| 조회(PENDING) | viewPending | 승인대기 | 승인대기 조회 전용. 모든 필드 disabled. 승인철회만 가능 |

## 레이아웃

- **GNB**: 다크 헤더(#1a1a2e) — 로고, BO 관리자, 사용자 정보
- **LNB**: 확장형 사이드바 — 상품 관리 그룹 확장, "배송상품 등록/수정" 활성

- **등록정보 차별화**: `.form-section--readonly` 클래스 — 읽기전용 영역은 `#f9fafb` 배경으로 편집 영역과 구분.

- 이미지 최대 5개, 최초 등록 시 대표 자동 설정
- 테이블: 대표(라디오) | 파일명 | 등록 | 삭제
- 미리보기 placeholder (120x120) + alt text

##### 영역 6.2: 동영상 등록

- mp4 최대 1개
- 파일명 | 등록 | 삭제
- FO 노출 순서: 동영상 > 이미지

##### 영역 6.3: 상품상세설명

- 적용 범위 radio (전체/PC)
  - 전체: PC 편집기 내용이 모바일에 자동 적용 → 모바일 편집기 비활성
  - PC: 모바일 편집기 영역 활성화 → PC/모바일 각각 등록
- PC HTML 편집기: editor-placeholder
- 모바일 HTML 편집기: editor-placeholder (전체 선택 시 disabled)

#### 탭 7: 상품정보제공고시 (편집 가능 폼)

| 필드 | UI 유형 | 비고 |

## 탭 순차 저장 플로우 (등록 모드 전용)

```
기본정보 저장 → 전시정보 활성화
전시정보 저장 → 판매정보 활성화
판매정보 저장 → 옵션/재고 활성화
옵션/재고 저장 → 배송정보 활성화
배송정보 저장 → 상세정보 활성화
상세정보 저장 → 상품정보제공고시 활성화
상품정보제공고시 저장 → 승인요청 버튼 활성화
```

- 등록 모드 진입 시: 탭 1(기본정보)만 활성, 나머지 탭 disabled + 시각적 비활성
- 각 탭 저장 성공 시: 다음 탭 활성화 + 자동 이동 + 성공 토스트
- 수정 모드: 모든 탭 활성 (순차 제한 없음)
- 조회 모드: 모든 탭 활성 (필드만 disabled)
