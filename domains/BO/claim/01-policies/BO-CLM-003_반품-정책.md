# 반품 정책

## 목적

배송형 주문에 대한 반품 클레임의 세부 정책(개요·조건·상태값·처리 플로우)을 정의한다. 본 문서는 [BO-CLM-001](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md)의 공통 정책을 전제로 하며, 반품 유형에만 적용되는 규칙을 담는다. 공통 정책의 귀책·배송비·재고·쿠폰 원복·단위 체계는 본 문서에 중복 기술하지 않으며 필요 시 공통 정책 해당 섹션을 참조한다.

---

## 1. 반품 개요 및 조건

### (1) 반품 개요

- **반품 클레임**은 **배송주문에만** 발생하는 클레임 유형으로, **배송완료 이후** 변심 또는 상품(서비스) 불량 등의 사유로 반품을 요청하는 것이다.
- 구매한 **단품(옵션)의 수량 단위**로 부분 반품 신청이 가능하다([BO-CLM-001 §2-(2)](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#2-클레임-기본-정책)).
- 반품은 구매자가 직접 신청할 수 있으며, 신청 이후 **BO/PO 관리자 승인**을 얻어야만 반품 절차가 진행된다.
- FO 구매자는 **반품 신청 이후 반품접수 전까지** 철회가 가능하다.

### (2) 반품 불가 사유

다음 경우 반품이 불가하다(반품 거부 또는 검수 거부 대상).

| # | 사유 |
|---|------|
| ① | 반품 가능 기간이 경과된 경우 |
| ② | 고객의 책임 있는 사유로 상품/서비스가 **멸실 또는 훼손**된 경우 |
| ③ | **포장을 개봉하였거나 포장이 훼손**되어 상품가치가 현저히 상실된 경우 (예: 식품 등) |
| ④ | 고객의 **사용 또는 일부 소비**에 의하여 상품의 가치가 현저히 감소한 경우 (예: 라벨이 떨어진 의류) |
| ⑤ | **시간의 경과**에 의하여 재판매가 곤란할 정도로 상품 등의 가치가 현저히 감소한 경우 |

### (3) 반품 가능 조건

| # | 조건 | 설명 |
|---|------|------|
| ① | 주문 상태가 **배송완료로 변경된 후 8일 이내** | BO 기준 **구매확정 이전 상태**에 한함 |
| ② | **교환 이후 반품** 진행 시 **교환배송완료 8일 이내** | BO 기준 구매확정 이전 상태 |
| ③ | 반품 가능 기간 경과 후에는 **CS 접수**를 통해 신청 | 본 자동 플로우 범위 외. CS 관리자가 수동 생성 |

> **참고:** 교환 이후 반품이 가능한 시점은 [BO-CLM-004 §1-(2)](../01-policies/BO-CLM-004_교환-정책.md#1-교환-개요-및-조건) 교환 조건과 연계된다.

## 2. 반품 클레임 상태값

반품은 주문취소와 달리 **물리적 수거·검수 과정**이 존재한다. 따라서 FO/BO 양측 모두 다단계 상태값을 갖는다.

### (1) 상태값 표 — 반품(사용자/대행)

| FO 클레임 상태 | BO/PO 클레임 상태값 | 처리 채널 | 내용 |
|----------------|---------------------|:---------:|------|
| 반품신청 | 반품신청 | FO | 구매자가 변심 혹은 상품/서비스 하자 등의 사유로 반품 신청 |
| 반품신청 | 반품신청 | BO/PO | 구매자의 플랫폼 외(고객센터 등) 반품 요청에 대해 관리자가 대행 신청 |
| 반품접수 | 반품접수 | BO/PO | 관리자가 반품 신청을 확인하고 **승인**한 상태 |
| 반품수거중 | 반품수거중 | BO/PO | 관리자가 **반송장 정보를 등록**하여 회수요청한 상태 |
| 반품상품수거 | 반품상품수거 | system | 반품 상품을 **택배사가 수령**한 상태 |
| 반품회수완료 | 반품회수완료 | system | 반품 상품이 **판매사로 회수 완료**된 상태 |
| 반품완료 | 환불요청 완료 | BO/PO | 관리자가 **수거 상품 검수 결과 최종 승인**하여 PG사에 결제 취소 및 복지포인트 복원 처리 요청 (*FO는 '반품완료' 표기) |
| 반품완료 | 환불완료 | system | PG 환불/복지포인트 복원 처리가 완료된 상태 |
| 반품완료 | 환불실패 | system | PG 환불 요청 실패 상태 (*1일 1회 환불요청 재전송 필요) |

### (2) 상태값 표 — 반품철회

| FO 클레임 상태 | BO/PO 클레임 상태값 | 처리 채널 | 내용 |
|----------------|---------------------|:---------:|------|
| 반품철회 | 반품철회 | FO | 구매자가 반품 신청 이후 **철회**한 상태 (배송상품만 가능). *이전 주문상태로 변경되며 해당 시점부터 카운트하여 정산 |
| 반품철회 | 반품철회 | BO/PO | ① 관리자가 반품신청 **거절** ② **CS 해결 등 비일반적 완결** 시. *이전 주문상태로 변경되며 해당 시점부터 카운트하여 정산 |

> **FO 철회 가능 시점:** `반품신청` 상태에서만 철회 가능. `반품접수` 이후(관리자 승인 후)는 FO 철회 불가 — CS로 문의.

### (3) 상태 전이 플로우

```
[FO 구매자 or BO/PO 대행] 반품신청
  → (BO/PO) 심사
    → 승인 → 반품접수
              → (BO/PO) 반송장 등록 → 반품수거중
                                         → (system) 택배사 수령 → 반품상품수거
                                                                      → (system) 판매사 회수 완료 → 반품회수완료
                                                                                                        → (BO/PO) 검수 통과·환불승인 → 환불요청 완료
                                                                                                                                          → (system) 성공 → 환불완료
                                                                                                                                          → (system) 실패 → 환불실패
                                                                                                                                                            → (BO/PO) 수기완료/재전송 → 환불완료
                                                                                                        → (BO/PO) 검수 거부(불가 사유 해당) → 반품철회 + 원상품 재배송
    → 반려 → 반품철회 (BO/PO)
  → [FO] 철회(반품접수 전까지) → 반품철회 (FO)
```

## 3. 반품 처리

### (1) 반품 수거

- 반품 수거는 **관리자(판매사)가 택배 수거**를 진행한다.
- 관리자는 반품접수 상태의 건에 대해 **반송장 정보**(택배사 + 송장번호 + 수거 요청일)를 등록하면 상태가 `반품수거중`으로 전환된다.
- 택배사가 상품을 수령하면 시스템이 수령 이벤트를 감지하여 `반품상품수거`로 전환한다.
- 상품이 판매사 창고에 회수 완료되면 시스템이 `반품회수완료`로 전환한다.

### (2) 반품 검수

- 회수 완료된 상품은 **판매사(또는 BO 관리자)가 검수**한다.
- 검수 결과는 다음 중 하나로 기록한다:
  - `PASSED` (통과) — 환불승인 진행
  - `FAILED_DEFECT` (구매자 귀책 훼손) — 검수거부
  - `FAILED_MISSING` (상품 누락) — 검수거부
  - `FAILED_OTHER` (기타) — 검수거부, 메모 필수
- 검수 결과의 세부 Enum은 [BO-CLM-010#InspectionResult](../02-data/BO-CLM-010_클레임-엔티티.md#InspectionResult)에 정의한다.

### (3) 환불승인 (검수 통과)

- 검수 결과가 `PASSED`인 경우 관리자가 **환불승인**을 수행하면 상태가 `환불요청 완료`로 전환된다.
- 이후 시스템이 PG/복지포인트 환불 프로세스를 자동 진행한다.
- 환불 처리 원칙 및 환불 방식은 [BO-CLM-001 §9](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#9-환불-처리-공통-원칙)에 따른다.
- 환불 실패 시 재전송·수기 완료는 주문취소와 동일한 로직을 사용한다([BO-CLM-002 §3-(4)](../01-policies/BO-CLM-002_주문취소-정책.md#3-주문취소-처리)).

### (4) 검수 거부 (반품 불가)

- 검수 결과가 `PASSED`가 아닌 경우 관리자는 **검수거부** 처리한다.
- 상태는 `반품철회` (BO/PO)로 전환되며, **원상품은 구매자에게 재배송**한다.
- 재배송 비용은 구매자 귀책으로 처리되며 원주문의 배송비 정책을 따른다.
- 거부 사유(Enum + 메모)가 이력에 저장되어 CS 문의 시 근거로 사용된다.

### (5) 부분 반품 시 원주문 재계산

- 부분 반품 처리한 원주문에 사용한 쿠폰은 [BO-CLM-001 §7](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#7-원주문-할인혜택-처리-정책)의 쿠폰 원복 상세 정책에 따라 원복 여부를 결정한다.
- 부분 반품으로 원주문이 **무료배송 최소 금액을 미달**하는 경우 추가 배송비가 원주문에 소급 부과될 수 있다.

## 4. 철회·거절 규칙

### (1) 구매자 철회 (FO)

- 구매자는 **`반품신청` 상태**에서만 철회 가능하다(`반품접수` 이후는 불가).
- 철회 시 원주문 상태는 반품 신청 이전 상태(`배송완료`)로 복원된다.
- 정산 카운트는 철회 시점부터 재시작된다.

### (2) 관리자 거절 (BO/PO)

- `반품신청` 단계의 건만 거절 가능.
- 거절 시 상태값은 `반품철회`(처리채널 BO/PO)로 전환된다.
- **반려사유**는 필수 입력(10~200자).
- 거절 시 FO 고객에게 거절 사유 및 CS 연결 안내 알림톡·메일이 발송된다.

## 5. 반품 배송비 정산

- 반품배송비 및 추가배송비 규칙은 [BO-CLM-001 §5](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#5-클레임-배송비-정책)를 따른다.
- 구매자 귀책 반품: 반품배송비는 환불금액에서 차감하거나 신청 시 별도 카드 결제.
- 판매사 귀책 반품: 반품배송비는 판매사 부담(구매자 전액 환불).

## 6. 제약 조건

| 제약 | 설명 |
|------|------|
| 가능 기간 | 배송완료(또는 교환배송완료) 후 **8일 이내** 신청 (FO). BO/PO는 소스 기준 기간 경과 후에도 수동 접수 가능 |
| 중복 신청 | 동일 주문상품(옵션)에 `반품신청`~`반품회수완료` 상태의 건이 있으면 추가 반품 신청 불가 |
| 수량 단위 | 수량 단위 부분 반품 허용 (옵션별) |
| 단품 단위 | 상품 단위가 아닌 **옵션별/수량별** 신청 |
| 교환 후 반품 | 교환 최종 승인 이후 재배송이 완료된 상태에서 8일 이내 반품 가능 |

## 7. 상태값 매트릭스 (BO 관리자 가능 액션)

| BO 상태값 | 발생 채널 | BO 관리자 가능 액션 |
|-----------|-----------|---------------------|
| 반품신청 (FO/BO 대행) | FO, BO/PO | **승인** → 반품접수 / **거절** → 반품철회 |
| 반품접수 | BO/PO | **수거요청** (반송장 등록) → 반품수거중 |
| 반품수거중 | BO/PO | 모니터링 (시스템 전이 대기) |
| 반품상품수거 | system | 모니터링 |
| 반품회수완료 | system | **환불승인** → 환불요청 완료 / **검수거부** → 반품철회(재배송) |
| 환불요청 완료 | BO/PO | 조회 / (실패 시 수기 완료·재전송) |
| 환불완료 | system / BO/PO | 조회만 (종결) |
| 환불실패 | system | **환불 재전송** 또는 **수기 완료** |
| 반품철회 | FO / BO/PO | 조회만 (종결) |

## 적용 범위

- **시스템:** BO 관리자 시스템
- **사용자:** BO 관리자, PO 파트너 관리자
- **대상 주문:** 배송형 주문(배송완료 ~ 구매확정 이전)
- **예외:**
  - 배송중·결제완료·상품준비중 단계는 반품 불가 — 주문취소 플로우로 진행
  - 반품 가능 기간 경과 후 자동 신청 불가 — CS 수동 접수 필요
  - 티켓형 주문(반품 개념 없음)
