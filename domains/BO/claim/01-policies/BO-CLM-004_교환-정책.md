# 교환 정책

## 목적

배송형 주문에 대한 교환 클레임의 세부 정책(개요·조건·상태값·처리 플로우)을 정의한다. 본 문서는 [BO-CLM-001](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md)의 공통 정책 및 [BO-CLM-003](../01-policies/BO-CLM-003_반품-정책.md)의 반품 조건을 전제로 한다. 반품과 공유되는 불가 사유·가능 조건·쿠폰 원복 등은 중복 기술하지 않고 참조한다.

---

## 1. 교환 개요 및 조건

### (1) 교환 개요

- **교환 클레임**은 **배송주문에만** 발생하는 클레임 유형으로, **배송완료 이후** 변심 또는 상품 불량 등의 사유로 교환을 요청하는 것이다.
- 플랫폼 내 교환은 구매자가 **원주문의 상품을 먼저 반품**하고, 관리자가 확인 후 **교환 상품을 배송**하는 방식만 제공한다.
- 구매한 **단품(옵션)의 수량 단위**로 부분 교환 신청이 가능하다([BO-CLM-001 §2-(2)](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#2-클레임-기본-정책)).
- 교환 클레임은 **동일 상품, 동일 가격의 옵션으로만 교환 가능**하다. 다른 상품·다른 가격 옵션은 반품 후 신규 주문으로 진행한다.
- 교환은 구매자가 직접 신청할 수 있으며, 신청 이후 **관리자 승인**을 얻어야만 교환 절차가 진행된다.
- 교환은 신청 이후 **교환접수 전까지** 철회가 가능하다.
- **재교환은 횟수에 관계없이 가능**하며, 교환 이후 반품 신청도 가능하다(교환배송완료 후 8일 이내).

### (2) 교환 조건

- **교환 불가 사유** 및 **교환 가능 기간**은 반품 클레임의 조건과 동일하다.
- 상세는 [BO-CLM-003 §1-(2)](../01-policies/BO-CLM-003_반품-정책.md#1-반품-개요-및-조건) 반품 불가 사유 및 [BO-CLM-003 §1-(3)](../01-policies/BO-CLM-003_반품-정책.md#1-반품-개요-및-조건) 반품 가능 조건을 참조한다.
- **교환배송완료 후 8일 경과 시** 재교환 및 반품 신청은 불가하다. 이후는 CS 수동 접수.

### (3) 교환 대상 제약

| 제약 | 설명 |
|------|------|
| **동일 상품** | 원주문의 상품과 **동일한 상품 ID(product_id)**에 한함 |
| **동일 가격** | 원주문 결제 시점의 **옵션 단가와 동일한 가격**의 옵션에 한함 |
| **재고 차감** | 교환 신청 시점에 교환 상품(옵션)의 **재고를 선차감**한다 ([BO-CLM-001 §6](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#6-클레임-재고-변경-정책) 예외 조항) |
| **재고 복원** | 교환이 최종 거절·철회·검수거부로 종결되는 경우 차감된 재고를 복원 |

## 2. 교환 클레임 상태값

교환은 반품과 유사한 **물리적 수거·검수 과정**을 거치되, 최종 단계에서 **환불 대신 교환주문 발급·재배송**으로 종결된다.

### (1) 상태값 표 — 교환

| FO 클레임 상태 | BO/PO 클레임 상태값 | 처리 채널 | 내용 |
|----------------|---------------------|:---------:|------|
| 교환신청 | 교환신청 | FO | 구매자가 변심 혹은 상품/서비스 하자 등의 사유로 교환 신청 |
| 교환접수 | 교환접수 | BO/PO | 관리자가 교환 신청을 확인하고 **승인**한 상태 |
| 교환수거중 | 교환수거중 | BO/PO | 관리자가 **반송장 정보를 등록**하여 회수요청한 상태 |
| 교환상품수거 | 교환상품수거 | system | 교환 반품 상품을 **택배사가 수령**한 상태 |
| 교환회수완료 | 교환회수완료 | system | 교환 반품 상품이 **판매사로 회수 완료**된 상태 |
| 교환최종승인 | 교환최종승인 | BO/PO | 교환 신청에 대해 관리자가 **수거 상품 검수 결과 교환 최종 승인**한 상태. 최종 승인 시 **주문관리 메뉴에서 교환주문번호 확인 가능** |

### (2) 상태값 표 — 교환철회

| FO 클레임 상태 | BO/PO 클레임 상태값 | 처리 채널 | 내용 |
|----------------|---------------------|:---------:|------|
| 교환철회 | 교환철회 | FO | 구매자가 교환 신청 이후 교환을 **철회**한 상태. 교환 신청 이전 주문상태로 자동 변경되며 **정산 시점 재카운트** |
| 교환철회 | 교환철회 | BO/PO | ① 관리자가 교환신청 **거절** ② **CS 해결 등 비일반적 상황 대응** → 교환 신청 이전 주문상태로 자동 변경되며 정산 시점 재카운트 |

> **FO 철회 가능 시점:** `교환신청` 상태에서만 철회 가능. `교환접수` 이후(관리자 승인 후)는 FO 철회 불가 — CS로 문의.

### (3) 상태 전이 플로우

```
[FO 구매자 or BO/PO 대행] 교환신청 (+ 교환 대상 옵션 선택, 재고 선차감)
  → (BO/PO) 심사
    → 승인 → 교환접수
              → (BO/PO) 반송장 등록 → 교환수거중
                                         → (system) 택배사 수령 → 교환상품수거
                                                                      → (system) 판매사 회수 완료 → 교환회수완료
                                                                                                        → (BO/PO) 검수 통과·최종승인 → 교환최종승인
                                                                                                                                         → (system) 교환주문번호 발급 + 재배송 트리거
                                                                                                        → (BO/PO) 검수 거부(불가 사유 해당) → 교환철회 + 원상품 재배송 + 교환 재고 복원
    → 반려 → 교환철회 (BO/PO) + 교환 재고 복원
  → [FO] 철회(교환접수 전까지) → 교환철회 (FO) + 교환 재고 복원
```

## 3. 교환 처리

### (1) 교환 수거

- 교환 수거는 **관리자가 택배 수거를 요청**하여 진행한다.
- 관리자는 교환접수 상태의 건에 대해 **반송장 정보**(택배사 + 송장번호 + 수거 요청일)를 등록하면 상태가 `교환수거중`으로 전환된다.
- 택배사가 상품을 수령하면 시스템이 수령 이벤트를 감지하여 `교환상품수거`로 전환한다.
- 상품이 판매사 창고에 회수 완료되면 시스템이 `교환회수완료`로 전환한다.

### (2) 교환 검수

- 회수 완료된 상품은 **판매사(또는 BO 관리자)가 검수**한다.
- 검수 결과 Enum은 [BO-CLM-010#InspectionResult](../02-data/BO-CLM-010_클레임-엔티티.md#InspectionResult)를 따른다.
- `PASSED` → 교환 최종승인으로 진행. 그 외 결과는 **검수거부** 처리.

### (3) 교환 최종승인

- 검수 결과가 `PASSED`인 경우 관리자가 **교환 최종승인**을 수행하면 상태가 `교환최종승인`으로 전환된다.
- 시스템은 즉시 다음 처리를 자동 실행한다:
  1. **교환주문 발급** — 원주문과 연결된 신규 주문(`exchange_order_id`)이 생성되어 주문관리 모듈에서 확인 가능
  2. **재배송 트리거** — 교환 상품(선차감된 재고)을 구매자에게 재배송
  3. **ClaimHistory 기록** — 최종승인 이력 + 교환주문번호 저장
- 교환주문의 배송 상태는 주문관리 모듈에서 관리되며, 본 클레임은 `교환최종승인`에서 종결된다.

### (4) 검수 거부 (교환 불가)

- 검수 결과가 `PASSED`가 아닌 경우 관리자는 **검수거부** 처리한다.
- 상태는 `교환철회` (BO/PO)로 전환되며, **원상품은 구매자에게 재배송**한다.
- **교환 대상 옵션의 선차감 재고는 자동 복원**된다([BO-CLM-001 §6](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#6-클레임-재고-변경-정책)).
- 재배송 비용은 구매자 귀책으로 처리되며 원주문의 배송비 정책을 따른다.

### (5) 부분 교환 시 원주문 재계산

- 부분 교환 처리한 원주문에 사용한 쿠폰은 [BO-CLM-001 §7](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#7-원주문-할인혜택-처리-정책)의 쿠폰 원복 상세 정책에 따라 원복 여부를 결정한다.
- 교환은 **동일 가격 옵션**만 허용하므로 **환불 정산은 발생하지 않는다**. 단, 교환배송비(왕복)는 귀책에 따라 처리한다([BO-CLM-001 §5](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#5-클레임-배송비-정책)).

## 4. 철회·거절 규칙

### (1) 구매자 철회 (FO)

- 구매자는 **`교환신청` 상태**에서만 철회 가능하다(`교환접수` 이후는 불가).
- 철회 시 교환 대상 옵션의 **선차감 재고가 자동 복원**된다.
- 원주문 상태는 교환 신청 이전 상태(`배송완료`)로 복원된다.
- 정산 카운트는 철회 시점부터 재시작된다.

### (2) 관리자 거절 (BO/PO)

- `교환신청` 단계의 건만 거절 가능.
- 거절 시 상태값은 `교환철회`(처리채널 BO/PO)로 전환된다.
- **반려사유**는 필수 입력(10~200자).
- **교환 대상 옵션의 선차감 재고가 자동 복원**된다.
- FO 고객에게 거절 사유 및 CS 연결 안내 알림톡·메일이 발송된다.

## 5. 교환 배송비 정산

- 교환배송비(왕복) 및 추가배송비 규칙은 [BO-CLM-001 §5](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#5-클레임-배송비-정책)를 따른다.
- 구매자 귀책 교환: 교환배송비(왕복)는 구매자가 부담 — 신청 시 카드 결제 필수.
- 판매사 귀책 교환: 교환배송비(왕복)는 판매사 부담.

## 6. 제약 조건

| 제약 | 설명 |
|------|------|
| 가능 기간 | 배송완료(또는 교환배송완료) 후 **8일 이내** 신청 (FO). 기간 경과 후 자동 신청 불가 |
| 교환 대상 | **동일 상품 · 동일 가격 옵션**만 허용. 다른 상품/다른 가격 옵션은 반품 후 신규 주문 |
| 재고 | 신청 시점 **교환 상품 재고 선차감**. 종결(최종승인/철회/거절/검수거부) 시 확정 또는 복원 |
| 중복 신청 | 동일 주문상품(옵션)에 진행 중 교환 클레임이 있으면 추가 신청 불가 |
| 재교환 | 횟수 무제한. 단, 직전 교환배송완료 이후 8일 이내만 가능 |
| 교환 후 반품 | 교환배송완료 8일 이내 반품 가능([BO-CLM-003 §1-(3)](../01-policies/BO-CLM-003_반품-정책.md#1-반품-개요-및-조건)) |

| 교환철회 | FO / BO/PO | 조회만 (종결). 재고 복원 이력 확인 |

## 적용 범위

- **시스템:** BO 관리자 시스템, 주문 관리 모듈(교환주문 발급 연계)
- **사용자:** BO 관리자, PO 파트너 관리자
- **대상 주문:** 배송형 주문(배송완료 ~ 구매확정 이전)
- **예외:**
  - 배송중·결제완료·상품준비중 단계는 교환 불가 — 주문취소 플로우 진행
  - 다른 상품·다른 가격 옵션 교환 요청 — 반품 후 신규 주문 유도
  - 티켓형 주문(교환 개념 없음, 소스 문서 명시)
