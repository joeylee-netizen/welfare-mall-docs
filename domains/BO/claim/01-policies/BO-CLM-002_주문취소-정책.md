# 주문취소 정책

## 목적

배송형 주문에 대한 주문취소 클레임의 세부 정책(개요·조건·상태값·환불 처리)을 정의한다. 본 문서는 [BO-CLM-001](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md)의 공통 정책을 전제로 하며, 주문취소 유형에만 적용되는 규칙을 담는다.

---

## 1. 주문취소 개요 및 조건

### (1) 주문취소 개요

- **주문취소 클레임**은 구매자가 **배송 시작 전** 또는 **티켓 발급 처리 전**에 변심 등의 사유로 주문취소를 요청하는 것이다.
- **배송상품**은 구매한 단품(옵션)별로 **부분 주문취소** 신청이 가능하며, 수량 단위 취소는 쿠폰 사용 등으로 수량별 상품주문번호가 구분된 경우에만 허용한다([BO-CLM-001 §2-(2)](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#2-클레임-기본-정책) 참조).
- 주문취소 클레임은 구매자가 직접 신청할 수 있으며, **배송주문의 상품준비중 단계를 제외**하고는 BO/PO 관리자 승인 절차 없이 신청 즉시 주문취소 절차가 진행된다.
- FO 구매자는 주문취소를 **주문취소완료(환불완료) 이전까지** 철회할 수 있다.

### (2) 주문취소 가능 조건 (FO)

| # | 조건 | 설명 |
|---|------|------|
| ① | FO 주문의 상태가 **결제완료** 또는 **상품준비중** | 배송중·배송완료 단계는 반품/교환 프로세스로 진행 |
| ② | **상품준비중** 상태인 경우 | BO/PO 관리자의 **수기 승인**을 거쳐 주문취소 처리 완료. 승인 거절 시 반품/교환 클레임으로 진행해야 한다. |
| ③ | **취소 가능 기간이 경과**한 경우 | 반품/교환 클레임으로 진행해야 한다. |

### (3) 주문취소 처리 주체별 분류

주문취소 클레임은 **누가 취소를 신청하였는가**에 따라 두 가지 하위 유형으로 나뉜다.

| 하위 유형 | 신청 주체 | 대표 상태값 | 발생 케이스 |
|-----------|-----------|-------------|-------------|
| **주문취소(사용자)** | FO 구매자 또는 BO/PO 대행 접수 | `주문취소 신청` → ... | 구매자 변심, 고객센터 요청 대행 |
| **판매취소(관리자)** | BO/PO 관리자 직접 접수 | `판매취소 신청` → ... | 상품 품절, 발송 불가, 판매사 일방 취소 사유 |

## 2. 주문취소 클레임 상태값

### (1) 상태값 — 주문취소(사용자)

FO 구매자가 신청(또는 BO/PO가 고객센터 요청을 대행 접수)한 주문취소의 상태 변화.

| FO 클레임 상태 | BO/PO 클레임 상태값 | 처리 채널 | 내용 — 배송상품 |
|----------------|---------------------|:---------:|------------------|
| 주문취소 | 주문취소 신청 | FO | 결제완료, 상품준비중 단계에서 구매자가 FO에서 주문취소 신청한 상태 |
| 주문취소 | 주문취소 신청 | BO/PO | 구매자의 플랫폼 외(고객센터 등) 주문취소 요청을 BO/PO 관리자가 대행하여 취소 신청한 상태 |
| 주문취소 | 환불요청 완료 | system | **결제완료** 단계의 주문취소 신청에 대해 주문 취소 처리를 완료하여 PG사에 결제 취소 요청, 복지포인트 복원 요청 상태 |
| 주문취소 | 환불요청 완료 | BO/PO | **상품준비중** 단계의 주문취소 신청에 대해 관리자가 수기 승인하여 PG사 결제 취소 요청, 복지포인트 복원 처리 요청한 상태 |
| 주문취소 | 환불완료 | system | PG 환불/복지포인트 복원 처리가 **모두 완료**된 상태 |
| 주문취소 | 환불완료 | BO/PO | `환불요청 완료` 혹은 `환불실패` 상태 건에 대해 관리자가 **수기 완료** 처리한 상태 |
| 주문취소 | 환불실패 | system | PG 환불 요청에 대해 **실패 응답**을 받은 상태. (*1일 1회 환불실패 상태 건에 대해 환불요청 재전송 필요) |
| 주문취소 철회 | 주문취소 철회 | FO | 주문취소 신청 단계에서 구매자가 **철회**한 상태 |
| 주문취소 철회 | 주문취소 철회 | BO/PO | 주문취소 신청 단계에서 BO/PO 관리자가 **반려**한 상태(반품/교환 전환 안내) |

### (2) 상태값 — 판매취소(관리자)

BO/PO 관리자가 품절·발송불가 등 사유로 신청한 판매취소의 상태 변화.

| FO 클레임 상태 | BO/PO 클레임 상태값 | 처리 채널 | 내용 — 배송상품 |
|----------------|---------------------|:---------:|------------------|
| 주문취소 | 판매취소 신청 | BO/PO | 주문 상품의 품절 등으로 BO/PO 관리자가 취소 신청한 상태 |
| 주문취소 | 환불요청 완료 | system | 판매취소 신청 건에 대해 주문 취소 처리 및 PG사 결제 취소 요청, 복지포인트 복원 처리를 요청한 상태 |
| 주문취소 | 환불완료 | system | PG 환불/복지포인트 복원 처리가 모두 완료된 상태 |
| 주문취소 | 환불완료 | BO/PO | `환불요청 완료` 혹은 `환불실패` 상태 건에 대해 BO/PO 관리자가 수기 완료 처리한 상태 |
| 주문취소 | 환불실패 | system | PG 환불 요청에 대해 실패 응답을 받은 상태. (*1일 1회 환불실패 상태 건에 대해 재전송 필요) |

> **판매취소에는 `주문취소 철회` 상태가 존재하지 않는다.** 관리자가 신청한 직후 시스템이 즉시 환불 요청 단계로 진행하기 때문이다.

### (3) 상태 전이 플로우

#### ① 주문취소(사용자) — 결제완료 단계

```
[FO 구매자] 주문취소 신청
  → (system) 즉시 전환: 환불요청 완료
    → (system) PG 환불 성공 + 포인트 복원 성공
      → 환불완료 (system)
    → (system) PG 환불 실패
      → 환불실패 (system)
        → (BO/PO) 수기 완료 또는 재전송
          → 환불완료 (BO/PO)
```

#### ② 주문취소(사용자) — 상품준비중 단계

```
[FO 구매자 or BO/PO 대행] 주문취소 신청
  → (BO/PO) 수기 심사
    → 승인 → 환불요청 완료 (BO/PO)
                → (system) 환불 성공 → 환불완료
                → (system) 환불 실패 → 환불실패 → 수기 완료/재전송
    → 반려 → 주문취소 철회 (BO/PO) + 반품/교환 전환 안내
```

#### ③ 판매취소(관리자)

```
[BO/PO 관리자] 판매취소 신청
  → (system) 즉시 전환: 환불요청 완료
    → (system) 환불 성공 → 환불완료
    → (system) 환불 실패 → 환불실패 → (BO/PO) 수기 완료/재전송 → 환불완료
```

#### ④ 철회·반려

```
주문취소 신청 상태에서만 발생 가능.
  - 구매자 철회: FO에서만 실행
  - 관리자 반려: BO/PO만 가능, 반려사유 필수 입력, 반품/교환 유도 안내
```

## 3. 주문취소 처리 규칙

### (1) 승인·반려 규칙 (상품준비중 단계)

- **결제완료** 단계의 주문취소 신청은 **시스템 자동 처리**되며 BO/PO 수기 개입이 필요 없다.
- **상품준비중** 단계의 주문취소 신청은 **BO/PO 관리자의 수기 승인**이 필수이다.
  - 이미 포장·출고 준비가 시작된 경우 반려 후 **반품/교환**으로 유도할 수 있다.
  - 반려 시 **반려사유**를 필수로 입력한다(최대 200자).
- **판매취소**는 관리자가 직접 신청한 건이므로 추가 승인 없이 즉시 환불요청 단계로 진입한다.

### (2) 환불 처리 원칙

- 주문취소가 승인(또는 자동 수락)되면 결제 수단에 따라 환불이 진행된다.
- 결제수단별 환불 방식은 [BO-CLM-001 §9-(1)](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#9-환불-처리-공통-원칙)에 따른다.
- 추가 결제수단을 통해 복합결제한 경우 **PG결제수단 → 복지포인트** 순으로 환불 처리한다.

### (3) 부분 취소 환불 방식

- **부분 취소**의 경우 취소 대상 상품에 대한 결제 금액에 대해서만 복지포인트 복원 및 카드사 승인 취소가 이루어진다.
- **조건부 처리 항목**(배송비 무료 정책, 쿠폰 사용 정책 등)에 대한 **재적용 처리**가 함께 이루어진다.
  - 무료배송 최소 주문금액 미달 시 원주문에 배송비 소급 부과
  - 부분 취소한 원주문에 사용한 쿠폰은 [BO-CLM-001 §7](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#7-원주문-할인혜택-처리-정책)에 따라 원복 여부 결정
- **전체 취소**일 경우 사용된 쿠폰은 시스템이 자동 복원한다.

### (4) 환불실패 처리

- `환불실패` 상태는 PG 환불 요청에 대해 PG사가 실패 응답을 반환한 경우 발생한다.
- **시스템 자동 재전송:** 1일 1회 시스템 배치가 `환불실패` 상태 건에 대해 환불 요청을 재전송한다.
- **수동 재전송:** 관리자는 BO 주문취소 상세 화면에서 **환불 재전송** 버튼을 클릭하여 즉시 재시도할 수 있다(당일 수동 재시도 횟수 제한: 1회).
- **수기 완료:** 관리자가 외부 경로(PG사 관리 콘솔 등)로 환불을 직접 처리한 경우, **환불완료** 수기 처리를 통해 상태를 확정할 수 있다.

## 4. 철회·반려 규칙

### (1) 구매자 철회 (FO)

- 구매자는 **`주문취소 신청` 상태**에서만 철회할 수 있다(`환불요청 완료` 이후는 불가).
- 철회 시 원주문 상태는 취소 전 상태(결제완료 또는 상품준비중)로 복원된다.

### (2) 관리자 반려 (BO/PO)

- **상품준비중** 단계의 `주문취소 신청` 건만 반려 가능하다.
- 반려 시 상태값은 `주문취소 철회`(처리채널 BO/PO)로 전환된다.
- 반려사유는 **필수 입력**(10~200자).
- 반려 시 FO 고객에게 다음 중 하나를 안내한다:
  - **출고 준비 완료**: 이미 출고 단계로 진행되어 취소 불가 → 반품 프로세스 안내
  - **배송 시작 임박**: 배송 중 수령 거부로 반품 진행 가능 안내
  - **기타 사유**: CS 연결 안내

## 5. 주문취소 신청 제약

| 제약 | 설명 |
|------|------|
| 중복 신청 | 동일 주문상품(옵션) 단위에 `주문취소 신청`·`환불요청 완료` 상태의 건이 있으면 추가 신청 불가 |
| 단계 제한 | 배송중·배송완료 주문상품은 주문취소 불가(반품/교환만 가능) |
| 수량 단위 | 수량별 주문번호가 구분된 경우에만 수량 단위 부분취소 허용([BO-CLM-001 §2-(2)](../01-policies/BO-CLM-001_클레임-관리-공통-정책.md#2-클레임-기본-정책)) |
| 쿠폰 연계 | 부분취소로 쿠폰 사용조건 미달 시 원주문 쿠폰 원복 자동 실행 |
| 배송비 재정산 | 부분취소로 무료배송 조건 미달 시 원주문 배송비 소급 부과 |

## 6. 상태값 매트릭스 (BO 관리자 화면 표시 기준)

| BO/PO 상태값 | 발생 채널 | BO 관리자 가능 액션 |
|--------------|-----------|---------------------|
| 주문취소 신청 (FO) | FO | (상품준비중 건) 승인 / 반려 / 대기 |
| 주문취소 신청 (BO/PO) | BO/PO 대행 | (상품준비중 건) 승인 / 반려 / 대기 |
| 판매취소 신청 | BO/PO | 시스템 자동 처리(관리자 액션 없음, 모니터링 대상) |
| 환불요청 완료 | system / BO/PO | 조회 / (실패 시) 수기 완료·재전송 |
| 환불완료 | system / BO/PO | 조회만 가능 (종결) |
| 환불실패 | system | **환불 재전송** 또는 **수기 완료 처리** |
