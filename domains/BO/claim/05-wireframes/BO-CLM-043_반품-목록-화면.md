# 반품 목록 화면

## 수정 이력

| 버전 | 날짜 | 작성자 | 변경 내용 |
|------|------|--------|----------|

## 화면 개요

배송형 **반품 클레임**을 전담 조회·처리하는 BO 화면이다. [BO-CLM-040 통합 목록](./BO-CLM-040_배송상품-클레임-목록-화면.md)과 별개로 LNB에서 직접 진입하며, BO/PO 작업 흐름에 특화되어 있다: (a) 반품신청 건 수기 승인·거절, (b) 반품접수 건 수거요청(반송장 등록), (c) 반품회수완료 건 환불승인·검수거부, (d) 환불실패 건 재전송.

## 레이아웃

- **GNB**: 다크 헤더 — "반품 목록" 활성
- **LNB**: 확장형 — `클레임관리 > 배송상품 클레임 > 반품 목록` 활성
- **Content**: 타이틀 → 검색 필터(14개) → 상단 툴바(일괄 처리 5개 버튼) → 테이블(27컬럼, 가로 스크롤, 긴급 행 강조) → 페이지네이션 + 모달(승인/거절/수거요청/환불승인/검수거부/재전송)

## 구성 요소

### 검색/필터 영역 (14개)

- 컴포넌트 참조: [BO-CLM-023 §검색 필터](../03-components/BO-CLM-023_반품-목록-테이블.md#검색-필터-구성-14개)
- 기간 / 하위유형 / FO상태 / BO상태 / 처리채널 / 접수채널 / 귀책 / 사유 / 검수결과 / 판매사 / 고객사 / 환불수단 / 택배사 / 검색어

### 상단 툴바 (일괄 처리)

- 좌측: 조회결과 N건 + 선택 M건
- 우측 버튼:
  - [일괄 승인] — `RETURN_REQUESTED` 대상
  - [일괄 거절] — `RETURN_REQUESTED` 대상
  - [일괄 수거요청] — `RETURN_RECEIVED` 대상 (반송장 행별 입력 모달)
  - [일괄 환불승인] — `RETURN_COLLECTED` 대상
  - [일괄 환불재전송] — `REFUND_FAILED` 대상
  - [엑셀 다운로드]
  - 출력건수 (20/50/100)

### 목록 테이블 (27컬럼)

- 컴포넌트 참조: [BO-CLM-023 §컬럼 구성](../03-components/BO-CLM-023_반품-목록-테이블.md#컬럼-구성-27개)
- 기본 정렬: `신청일시 DESC`
- **긴급 행 강조**: `RETURN_REQUESTED` / `RETURN_COLLECTED` / `REFUND_FAILED` 행은 `#fff7ed` 배경 + ⚠️ 아이콘
- 개별 처리 버튼(상태별 분기): 승인/거절 / 수거요청 / 환불승인/검수거부 / 수기완료/재전송

### 모달 (6개)

1. **승인 확인 모달** — 단건/일괄
2. **거절 사유 입력 모달** — 반려사유(10~200자) + FO 안내 템플릿(반품 불가 5사유 라디오)
3. **수거요청 모달** — 택배사/송장번호/수거 요청일 (일괄은 행별 입력 테이블)
4. **환불승인 모달** — 검수 결과 PASSED 고정 + 검수 메모(선택)
5. **검수거부 모달** — 거부 사유 Radio(`FAILED_DEFECT/MISSING/OTHER`) + 메모(OTHER 시 필수)
6. **환불 재전송 확인 모달** — 당일 1회 제한 안내

### 페이지네이션

- 하단 중앙. 이전/다음, 페이지 번호.
