# 주문취소 상세 화면

## 수정 이력

| 버전 | 날짜 | 작성자 | 변경 내용 |
|------|------|--------|----------|
| v1.0 | 20260421 | 기획자 | 신규 작성 — 모달형 상세 화면, 5개 정보 섹션 + 처리 이력 타임라인 + 모드별 하단 버튼 |

## 화면 개요

주문취소 클레임의 전체 정보를 조회하고 상태별 처리(승인/반려/환불완료/재전송)를 수행하는 **모달형 상세 화면**이다. [BO-CLM-020 통합 목록](./BO-CLM-040_배송상품-클레임-목록-화면.md) 또는 [BO-CLM-041 주문취소 목록](./BO-CLM-041_주문취소-목록-화면.md)에서 클레임코드 클릭 시 오버레이로 열린다.

## 레이아웃

- **배경 오버레이**: `rgba(0,0,0,0.5)` — 모달 뒤 스크롤 잠금
- **모달 박스**: 너비 1200px, 최대 높이 90vh, 내부 스크롤
- **헤더**: "주문취소 상세 [{claim_code}]" + [X] 닫기 버튼
- **본문**: 5개 섹션(클레임 정보 / 원주문 정보 / 취소 대상 상품 / 환불 상세 / 처리 이력)
- **푸터**: 모드별 버튼(좌측 닫기 / 우측 처리 버튼)

## 구성 요소

### 섹션 1: 클레임 정보

- 컴포넌트 참조: [BO-CLM-022 §섹션 1](../03-components/BO-CLM-022_주문취소-상세-폼.md#섹션-1-클레임-정보)
- 2열 key-value 레이아웃 (12개 필드)

### 섹션 2: 원주문 정보

- 컴포넌트 참조: [BO-CLM-022 §섹션 2](../03-components/BO-CLM-022_주문취소-상세-폼.md#섹션-2-원주문-정보)
- 주문번호/구매자/판매사 링크 처리
- 결제수단/금액 블록 표시

### 섹션 3: 취소 대상 상품

- 컴포넌트 참조: [BO-CLM-022 §섹션 3](../03-components/BO-CLM-022_주문취소-상세-폼.md#섹션-3-취소-대상-상품-claimitem-목록)
- ClaimItem 목록 테이블 + 합계 행

### 섹션 4: 환불 상세

- 컴포넌트 참조: [BO-CLM-022 §섹션 4](../03-components/BO-CLM-022_주문취소-상세-폼.md#섹션-4-환불-상세)
- 환불 요약 블록 + RefundRecord 목록 테이블(수단별 상태/시도/응답)

### 섹션 5: 클레임 처리 이력

- 컴포넌트 참조: [BO-CLM-022 §섹션 5](../03-components/BO-CLM-022_주문취소-상세-폼.md#섹션-5-클레임-처리-이력-타임라인)
- 세로 타임라인 (최신 순)

### 하단 버튼 영역

- 컴포넌트 참조: [BO-CLM-022 §모드 제어](../03-components/BO-CLM-022_주문취소-상세-폼.md#모드-제어-하단-버튼-분기)
- 상태별 버튼 구성:

| 상태 | 버튼 |
|------|------|
| `CANCEL_REQUESTED + approval_required=Yes` | [반려] [승인] |
| `CANCEL_REQUESTED + approval_required=No` | (없음) |
| `SALE_CANCEL_REQUESTED` | (없음) |
| `REFUND_REQUESTED` | [환불 수기 완료] |
| `REFUND_FAILED` | [환불 수기 완료] [환불 재전송] |
| `REFUNDED` / `CANCEL_WITHDRAWN` | (없음, 조회만) |

## 기능 명세

- 모달 오픈 시 [BO-CLM-032 상세 조회](../04-actions/BO-CLM-032_주문취소-상세-조회.md) 호출
- 처리 후 상세 재조회 + 호출측 목록 새로고침(refresh 플래그)
- ESC 키: 외곽 모달 닫기(처리 모달 열려 있으면 그 모달만)
- 배경 클릭: 무시(실수 방지)

### 처리 흐름

| 처리 | 액션 | 비고 |
|------|------|------|
| 승인 | [BO-CLM-035](../04-actions/BO-CLM-035_주문취소-승인.md) | 확인 모달 → 액션 호출 → 상세 재조회 |
| 반려 | [BO-CLM-036](../04-actions/BO-CLM-036_주문취소-반려.md) | 반려사유 입력 모달 → 액션 호출 → 상세 재조회 |
| 환불 수기 완료 | [BO-CLM-037](../04-actions/BO-CLM-037_환불-수기-완료.md) | 확인 모달(메모 입력) → 액션 호출 → 상세 재조회 |
| 환불 재전송 | [BO-CLM-038](../04-actions/BO-CLM-038_환불-재전송.md) | 확인 모달 → 액션 호출 → 상세 재조회 |

## 상태 처리

| 상태 | 설명 | UI 표현 |
|------|------|---------|
| 로딩 | 상세 API 호출 중 | 섹션별 skeleton |
| 조회 실패 | 데이터 로드 실패 | 모달 중앙 에러 메시지 + [재시도] |
| 권한 없음(403) | 타 고객사 건 | 모달 즉시 닫힘 + 상위 알림 배너 |
| 404 NOT_FOUND | 삭제/없는 클레임 | 모달 닫힘 + 토스트 "존재하지 않는 클레임입니다." |
| 처리 중 | 버튼 클릭 후 | 버튼 비활성 + 스피너 |
| 상태 충돌(409) | 진행 중 상태 변경 | 토스트 + 자동 재조회 |
| 재시도 한도 초과 | 환불 재전송 | 버튼 비활성 + 툴팁 |
