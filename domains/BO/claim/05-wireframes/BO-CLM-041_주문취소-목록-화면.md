# 주문취소 목록 화면

## 수정 이력

| 버전 | 날짜 | 작성자 | 변경 내용 |

## 화면 개요

배송형 **주문취소 클레임**을 전담 조회·처리하는 BO 화면이다. [BO-CLM-040 통합 목록](./BO-CLM-040_배송상품-클레임-목록-화면.md)과 별개 화면으로, BO/PO 작업 흐름에 특화되어 있다: (a) 상품준비중 건 수기 승인·반려, (b) 환불실패 재전송 대상 관리, (c) 일괄 처리 지원.

## 레이아웃

- **GNB**: 다크 헤더 — 탭에 "주문취소 목록" 활성
- **LNB**: 확장형 — `클레임관리 > 주문취소 목록` 활성
- **Content**: 타이틀 → 검색 필터(13개) → 상단 툴바(일괄 처리 버튼) → 테이블(가로 스크롤, 긴급 행 강조) → 페이지네이션 + 모달(승인 확인/반려 사유 입력/재전송 확인)

## 구성 요소

### 검색/필터 영역 (13개)

- 컴포넌트 참조: [BO-CLM-021 §검색 필터](../03-components/BO-CLM-021_주문취소-목록-테이블.md#검색-필터-구성-13개)
- 레이아웃: label:value 테이블형 2열 배치
- 필터 목록: 기간 / 하위 유형 / FO 상태 / BO 상태 / 처리 채널 / 접수 채널 / 승인 필요 여부 / 귀책 / 사유 / 판매사 / 고객사 / 환불 수단 / 검색어

### 상단 툴바 (일괄 처리)

- 좌측: 조회결과 N건 + 선택 M건
- 우측 버튼 그룹:
  - [일괄 승인] — 선택 전원이 `CANCEL_REQUESTED + approval_required=Yes`일 때만 활성
  - [일괄 반려] — 동일 조건 활성
  - [일괄 환불재전송] — 선택 전원이 `REFUND_FAILED`일 때만 활성
  - [엑셀 다운로드] — 상시 활성
  - 출력건수 선택 (20/50/100)

### 목록 테이블 (26컬럼)

- 컴포넌트 참조: [BO-CLM-021 §컬럼 구성](../03-components/BO-CLM-021_주문취소-목록-테이블.md#컬럼-구성-26개)
- 기본 정렬: `신청일시 DESC`
- **긴급 행 강조**: `approval_required = true` AND `claim_status_bo = CANCEL_REQUESTED` 행 `#fff7ed` 배경 + 행 앞부분에 🚨 아이콘
- **개별 처리 버튼:**
  - `승인/반려` 컬럼: 긴급 행에서만 활성
  - `환불재전송` 컬럼: `REFUND_FAILED` 행에서만 활성

### 모달

#### (1) 승인 확인 모달

- 헤더: "주문취소 일괄 승인" 또는 "주문취소 승인" (단건)
- 본문: "선택한 N건의 주문취소를 승인하시겠습니까? 승인 시 즉시 환불요청이 진행됩니다."
- 버튼: [취소] [승인]

#### (2) 반려 사유 입력 모달

- 헤더: "주문취소 반려"
- 본문 필드:
  - 반려사유 (textarea, 10~200자 필수)
  - FO 안내 문구 템플릿 라디오: `출고 준비 완료` / `배송 시작 임박` / `기타`
- 버튼: [취소] [반려 확정]

#### (3) 환불 재전송 확인 모달

- 헤더: "환불 재전송"
- 본문: "선택한 N건의 환불 요청을 재전송합니다. 당일 수동 재시도는 1회로 제한됩니다."
- 버튼: [취소] [재전송]

### 페이지네이션

- 하단 중앙. 이전/다음, 페이지 번호.

## 상태 처리

| 상태 | 설명 | UI 표현 |
|------|------|---------|
| 로딩 | API 호출 중 | skeleton + 버튼 비활성 |
| 데이터 없음 | 조회 결과 0건 | "조회 결과가 없습니다." + [필터 초기화] |
