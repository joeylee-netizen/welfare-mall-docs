## 화면 개요

배송형 주문에 대한 **전체 클레임**(주문취소·반품·교환)을 통합 조회하는 BO 화면이다. v2.0에서 탭 UI를 완전히 제거하고 **클레임 유형 필터**(체크박스: 전체/주문취소/반품/교환)로 전환했으며, 유형별 전용 화면(주문취소/반품/교환 목록)은 LNB에서 직접 진입한다. 행 클릭 시 행의 `claim_type`에 따라 유형별 상세 모달로 분기된다.

- 기본 조회: 전 유형(`claim_type` 필터 "전체")
- 유형별 전용 화면(분리 진입):
  - [주문취소 목록 (BO-CLM-041)](./BO-CLM-041_주문취소-목록-화면.md)
  - [반품 목록 (BO-CLM-043)](./BO-CLM-043_반품-목록-화면.md)
  - [교환 목록 (BO-CLM-045)](./BO-CLM-045_교환-목록-화면.md)

## 레이아웃

- **GNB**: 다크 헤더 — 로고, 탭, 관리자 정보
- **LNB**: 확장형 사이드바 — `클레임관리` 그룹 확장, 서브메뉴 4개 노출
  ```
  클레임관리
    ├─ 배송상품 클레임 (섹션 헤더)
    ├─ 배송상품 클레임 목록 (통합)  ← 현재 화면
    ├─ 주문취소 목록
    ├─ 반품 목록
    └─ 교환 목록
  ```
- **Content**: 페이지 타이틀 → 검색 필터(테이블형 2열, 15개) → 툴바 → 테이블(29컬럼, 가로 스크롤) → 페이지네이션

### 목록 테이블 (29컬럼)

- 컴포넌트 참조: [BO-CLM-020 §컬럼 구성](../03-components/BO-CLM-020_배송상품-클레임-목록-테이블.md#컬럼-구성-29개)
- 기본 정렬: `신청일시 DESC`
- 가로 스크롤 + `min-width: 3200px` (컬럼 확장 반영)
- **행 클릭 분기 (v2.0 신규):**
  - `CANCEL` → [BO-CLM-042 주문취소 상세](./BO-CLM-042_주문취소-상세-화면.md)
  - `RETURN` → [BO-CLM-044 반품 상세](./BO-CLM-044_반품-상세-화면.md)
  - `EXCHANGE` → [BO-CLM-046 교환 상세](./BO-CLM-046_교환-상세-화면.md)
- 주문번호 클릭: 주문관리 모듈 주문상세 새 탭
- **교환주문번호 셀 클릭 (v2.0 신규):** 교환주문 상세 새 탭
- 판매사·구매자 셀 클릭: 정보 팝업

### 상단 툴바

- 조회결과 N건 표시
- [엑셀 다운로드] 버튼 (최대 10,000건)
- 출력건수 선택: 20 / 50 / 100건

### 페이지네이션

- 하단 중앙. 이전/다음, 페이지 번호.

## 기능 명세

- 액션 참조: [BO-CLM-030](../04-actions/BO-CLM-030_클레임-목록-조회.md) — 클레임 목록 조회 (claim_type 필터 값 전송)
- 페이지 로드 시 `claim_type = 전체` 기본 조회
- 검색 버튼 또는 Enter 키 → 조회 실행
- 초기화 버튼 → 필터 기본값 복원 후 재조회
- 검색어 드롭박스 값이 `사용안함` 외 시: 1~14번 필터 비활성화
- 행의 `claim_type`에 따라 상세 모달 분기
