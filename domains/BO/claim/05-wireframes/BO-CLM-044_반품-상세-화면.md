# 반품 상세 화면

## 수정 이력

| 버전 | 날짜 | 작성자 | 변경 내용 |
|------|------|--------|----------|
| v1.0 | 20260422 | 기획자 | 신규 작성 — 모달형 반품 상세, 6개 섹션, 상태별 하단 버튼 분기 |

## 화면 개요

반품 클레임의 전체 정보를 조회하고 상태별 처리(승인/거절/수거요청/환불승인/검수거부/수기완료/재전송)를 수행하는 **모달형 상세 화면**. [BO-CLM-043 반품 목록](./BO-CLM-043_반품-목록-화면.md) 또는 [BO-CLM-040 통합 목록](./BO-CLM-040_배송상품-클레임-목록-화면.md)에서 클레임코드 클릭 시 오버레이로 열린다.

## 레이아웃

- **배경 오버레이**: `rgba(0,0,0,0.5)` — 뒤 스크롤 잠금
- **모달 박스**: 너비 1200px, 최대 높이 90vh, 내부 스크롤
- **헤더**: "반품 상세 [{claim_code}]" + [X]
- **본문**: 6개 섹션
- **푸터**: 좌측 [닫기] + 우측 상태별 처리 버튼

## 구성 요소

### 섹션 1: 클레임 정보

- 컴포넌트 참조: [BO-CLM-024 §섹션 1](../03-components/BO-CLM-024_반품-상세-폼.md#섹션-1-클레임-정보)
- 2열 key-value 레이아웃(11개 필드)

### 섹션 2: 원주문 정보

- 주문번호/주문자/판매사 링크, 배송지 full-width, 결제수단 블록

### 섹션 3: 반품 대상 상품

- ClaimItem 테이블 + 합계 행

### 섹션 4: 수거·검수 정보

- 반송장/택배사/수거 요청일/수령일/회수일 + 검수 결과/메모/검수자/검수일
- 택배사 추적 링크(외부) — 반송장 번호 클릭 시

### 섹션 5: 환불 상세

- 환불 요약 카드(4개) + RefundRecord 목록

### 섹션 6: 처리 이력 타임라인

- ClaimHistory 최신 순. 수거·검수 이벤트 모두 포함.

### 하단 버튼 영역

- 컴포넌트 참조: [BO-CLM-024 §모드 제어](../03-components/BO-CLM-024_반품-상세-폼.md#모드-제어-하단-버튼-분기)
- 상태별 분기:

| 상태 | 버튼 |
|------|------|
| `RETURN_REQUESTED` | [거절] [승인] |
| `RETURN_RECEIVED` | [수거요청] |
| `RETURN_PICKUP_IN_PROGRESS` / `PICKED_UP` | (모니터링) |
| `RETURN_COLLECTED` | [검수거부] [환불승인] |
| `REFUND_REQUESTED` | [환불 수기 완료] |
| `REFUND_FAILED` | [환불 수기 완료] [환불 재전송] |
| `REFUNDED` / `RETURN_WITHDRAWN` | (조회만) |

## 기능 명세

- 모달 오픈 시 [BO-CLM-032 상세 조회](../04-actions/BO-CLM-032_주문취소-상세-조회.md) 공용 액션 호출
- 처리 후 상세 재조회 + 호출측 목록 새로고침
- ESC: 외곽 모달 닫기(처리 모달 있으면 그것만)
- 배경 클릭: 무시

## 상태 처리

| 상태 | 표시 |
|------|------|
| 로딩 | 섹션별 skeleton |
| 조회 실패 | 중앙 에러 + [재시도] |
| 403 | 모달 닫힘 + 상위 알림 |
| 404 | 모달 닫힘 + 토스트 |
| 처리 중 | 버튼 비활성 + 스피너 |
| 409 상태 충돌 | 토스트 + 자동 재조회 |
| 재시도 한도 초과 | 재전송 버튼 비활성 + 툴팁 |
