# 교환 목록 화면

## 수정 이력

| 버전 | 날짜 | 작성자 | 변경 내용 |
|------|------|--------|----------|
| v1.0 | 20260422 | 기획자 | 신규 작성 — 교환 전용 목록, 긴급 행 강조, 교환 특화 컬럼(대상 옵션/교환주문번호/재배송 송장) |

## 화면 개요

배송형 **교환 클레임**을 전담 조회·처리하는 BO 화면. LNB에서 직접 진입한다. 반품 목록([BO-CLM-043](./BO-CLM-043_반품-목록-화면.md))과 유사 구조지만 교환 특화(교환 대상 옵션, 교환주문번호 발급, 재배송 송장) 컬럼·버튼을 포함한다.

## 레이아웃

- **GNB**: "교환 목록" 활성
- **LNB**: `클레임관리 > 배송상품 클레임 > 교환 목록` 활성
- **Content**: 타이틀 → 검색 필터(14개) → 상단 툴바(일괄 처리 4개 버튼 + 엑셀) → 테이블(28컬럼) → 페이지네이션 + 모달

## 구성 요소

### 검색/필터 영역 (14개)

- 컴포넌트 참조: [BO-CLM-025 §검색 필터](../03-components/BO-CLM-025_교환-목록-테이블.md#검색-필터-구성-14개)
- 기간 / 하위유형 / FO상태 / BO상태 / 처리채널 / 접수채널 / 귀책 / 사유 / 검수결과 / 판매사 / 고객사 / 택배사 / 교환주문번호 / 검색어

### 상단 툴바 (일괄 처리)

- 좌측: 조회결과 N건 + 선택 M건
- 우측 버튼:
  - [일괄 승인] — `EXCHANGE_REQUESTED`
  - [일괄 거절] — `EXCHANGE_REQUESTED` (반려사유 모달, 재고 복원 안내)
  - [일괄 수거요청] — `EXCHANGE_RECEIVED`
  - [일괄 최종승인] — `EXCHANGE_COLLECTED` (교환주문 발급 안내)
  - [엑셀 다운로드]
  - 출력건수 (20/50/100)

### 목록 테이블 (28컬럼)

- 컴포넌트 참조: [BO-CLM-025 §컬럼 구성](../03-components/BO-CLM-025_교환-목록-테이블.md#컬럼-구성-28개)
- 기본 정렬: `신청일시 DESC`
- **교환 특화 컬럼**: 원옵션 / 교환 대상 옵션 / 반송장 / 교환주문번호(링크) / 재배송 송장
- **긴급 행 강조**: `EXCHANGE_REQUESTED` / `EXCHANGE_COLLECTED` 행
- 개별 처리 버튼(상태별): 승인/거절 / 수거요청 / 최종승인/검수거부

### 모달

1. **승인 확인 모달** — "교환 대상 재고 선차감 상태 안내"
2. **거절 사유 입력 모달** — 반려사유 + **재고 복원 안내**
3. **수거요청 모달** — 택배사/송장번호/수거 요청일
4. **최종승인 모달** — 검수 PASSED 고정 + 검수 메모 + **교환주문 발급·재배송 안내**
5. **검수거부 모달** — 거부 사유 + 메모 + **재고 복원 + 원상품 재배송 안내**

### 페이지네이션

- 하단 중앙
