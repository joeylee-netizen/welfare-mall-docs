# 교환 상세 화면

## 수정 이력

| 버전 | 날짜 | 작성자 | 변경 내용 |
|------|------|--------|----------|
| v1.0 | 20260422 | 기획자 | 신규 작성 — 모달형 교환 상세, 7개 섹션(교환 요청 옵션 + 교환 최종승인 정보 추가) |

## 화면 개요

교환 클레임의 전체 정보를 조회하고 상태별 처리(승인/거절/수거요청/최종승인/검수거부)를 수행하는 **모달형 상세 화면**. 반품 상세([BO-CLM-044](./BO-CLM-044_반품-상세-화면.md))와 유사 구조지만 **교환 요청 옵션 섹션**과 **교환 최종승인 정보 섹션**이 추가된다.

## 레이아웃

- **배경 오버레이**: `rgba(0,0,0,0.5)`
- **모달 박스**: 너비 1200px, 최대 높이 90vh, 내부 스크롤
- **헤더**: "교환 상세 [{claim_code}]" + [X]
- **본문**: 7개 섹션
- **푸터**: 좌측 [닫기] + 우측 상태별 처리 버튼

## 구성 요소

### 섹션 1: 클레임 정보

- 컴포넌트 참조: [BO-CLM-026 §섹션 1](../03-components/BO-CLM-026_교환-상세-폼.md#섹션-1-클레임-정보)

### 섹션 2: 원주문 정보

- 주문번호·주문자·판매사 링크, 배송지, 결제수단 블록

### 섹션 3: 교환 대상 상품 (원상품)

- 원주문 ClaimItem 테이블

### 섹션 4: 교환 요청 옵션 (교환 전용)

- 컴포넌트 참조: [BO-CLM-026 §섹션 4](../03-components/BO-CLM-026_교환-상세-폼.md#섹션-4-교환-요청-옵션-교환-전용-신규-섹션)
- 교환 대상 상품/옵션/가격 일치 검증 배지 + 선차감 재고 상태
- 섹션 배경 `#eff6ff`로 시각 강조

### 섹션 5: 수거·검수 정보

- 반송장/택배사/수거 일정 + 검수 결과/메모/검수자

### 섹션 6: 교환 최종승인 정보 (교환 전용)

- 컴포넌트 참조: [BO-CLM-026 §섹션 6](../03-components/BO-CLM-026_교환-상세-폼.md#섹션-6-교환-최종승인-정보-교환-전용-신규-섹션)
- 최종승인 일시·승인자·**교환주문번호**(링크)·재배송 송장·재배송 상태
- 최종승인 전 단계에는 "진행 중" 표시

### 섹션 7: 처리 이력 타임라인

- ClaimHistory 최신 순. 재고 선차감/복원, 수거, 검수, 교환주문 발급 이벤트 포함.

### 하단 버튼 영역

- 컴포넌트 참조: [BO-CLM-026 §모드 제어](../03-components/BO-CLM-026_교환-상세-폼.md#모드-제어-하단-버튼-분기)
- 상태별 분기:

| 상태 | 버튼 |
|------|------|
| `EXCHANGE_REQUESTED` | [거절] [승인] |
| `EXCHANGE_RECEIVED` | [수거요청] |
| `EXCHANGE_PICKUP_IN_PROGRESS` / `PICKED_UP` | (모니터링) |
| `EXCHANGE_COLLECTED` | [검수거부] [최종승인] |
| `EXCHANGE_FINAL_APPROVED` / `EXCHANGE_WITHDRAWN` | (조회만) |

> 교환은 환불 프로세스가 없으므로 환불 수기 완료·재전송 버튼이 없다.

## 기능 명세

- 모달 오픈 시 [BO-CLM-032 상세 조회](../04-actions/BO-CLM-032_주문취소-상세-조회.md) 공용 액션 호출
- 교환주문번호 클릭 → 주문관리 모듈 주문상세 새 탭
- 재배송 송장 클릭 → 택배사 추적 페이지 새 탭
- 처리 후 상세 재조회 + 호출측 목록 새로고침
- ESC/배경: 반품 상세와 동일 처리

### 처리 흐름

| 처리 | 액션 | 비고 |
|------|------|------|
| 승인 | [BO-CLM-03A](../04-actions/BO-CLM-03A_반품교환-승인.md) | 확인 모달 |
| 거절 | [BO-CLM-03B](../04-actions/BO-CLM-03B_반품교환-거절.md) | 반려사유 + 재고 복원 안내 |
| 수거요청 | [BO-CLM-03C](../04-actions/BO-CLM-03C_반품교환-수거요청.md) | 반송장 등록 |
| 최종승인 | [BO-CLM-03E](../04-actions/BO-CLM-03E_교환-최종승인.md) | 검수 통과 + 교환주문 발급 |
| 검수거부 | [BO-CLM-03F](../04-actions/BO-CLM-03F_반품교환-검수거부.md) | 거부 사유 + 재고 복원 + 재배송 |

## 상태 처리

| 상태 | 표시 |
|------|------|
| 로딩 | 섹션별 skeleton |
| 조회 실패 | 재시도 |
| 403 / 404 | 모달 닫힘 + 상위 알림 |
| 처리 중 | 버튼 비활성 + 스피너 |
| 409 상태 충돌 | 자동 재조회 |
| **재고 선차감 부족** | 토스트 + 신청 거부 |
| **교환주문 발급 실패** | 토스트 + 재시도 버튼 활성 |
| **재고 복원 실패** | 토스트 + 이력 기록 + CS 알림 |
